## Goal

Run production taint / forbidden-data-flow queries as IFDS data-flow over the ICFG: existing typed sources → sanitizers → sinks with **replayable matched paths**. Delete any remaining heuristic reachability filter that still pads precision for these queries.

## Scope

- Migrate `policy_queries` / data-flow consumers that already express SourcePattern / SinkPattern / sanitizer edges onto IFDS fact domain (taint lattice / boolean tainted-with-sanitizer-kill — use what existing facts already model).
- Paths must come from `analysis/ifds` with call/return matching (already required by W4.2).
- **No** new source/sink kinds. **No** new security templates. Wire what exists.

## Hard rules

NO dual path engines. NO “BFS for taint, IFDS for reachability.” Complete migration. Delete obsolete filters/banks for the same queries.
