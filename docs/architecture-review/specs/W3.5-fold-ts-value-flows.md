# W3.5 — Fold or retire `ts_value_flows`

**Depends on:** W3.3 (Closure + captures)  
**Binding:** `.swarm/HUMAN-BINDING-2026-08-08-M3-M4.md`

## Goal

Eliminate the parallel TS frontend in `analysis/calls/ts_value_flows.rs` (~12k LOC): it re-parses with Oxc and builds its own resolver. Migrate its **existing** production callers onto MIR + shared call/points-to pipeline.

## Done when

- No production caller depends on `ts_value_flows` as a separate parse pipeline.
- File deleted or reduced to thin adapters over MIR facts (prefer delete).
- Call-graph / value-flow diagnostics for existing TS rules remain within golden tolerance (lock + regen only with evidence).
- Leak gate green.

## Anti-goals

Rewriting the Andersen solver. Adding features not already provided by the fork. Keeping a permanent “legacy value flows” module.
