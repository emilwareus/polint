# W3.2 — Effectful terminators (Throw / Call unwind / Suspend)

**Depends on:** W3.1  
**Binding:** `.swarm/HUMAN-BINDING-2026-08-08-M3-M4.md`

## Goal

Replace CFG construct-string recovery for throw, call exceptional edges, await/yield/channel-style suspend with real MIR terminators — for constructs Go/TS lowerers already surface.

## Terminator additions (delete string-matching CFG shapes they replace)

```rust
Throw { value: Option<MirValue>, unwind: MirBlockId },
Call {
    site: CallSiteId,
    callee: MirValue,
    arguments: Vec<PlaceId>,
    return_place: PlaceId,
    normal: MirBlockId,
    unwind: Option<MirBlockId>,
},
Suspend {
    kind: SuspendKind, // Await | Yield | ChannelRecv | ChannelSend
    value: Option<MirValue>,
    resume: MirBlockId,
},
```

## Done when

- CFG no longer maps `unsupported.construct == "throw"|"await"|…` via string tables for those shapes when MIR emitted the terminator.
- Goldens + leak gate green.
- No dual “string shape + terminator” for the same op.

## Anti-goals

New languages. New product capabilities beyond expressing control that already exists as unsupported/partial facts. SSA.
