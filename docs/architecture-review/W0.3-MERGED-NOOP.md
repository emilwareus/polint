# W0.3 — MERGED-NOOP (layering dogfood deferred)

**Status:** closed for the M0 gate without claiming layering is enforced.

## Why

polint’s language frontends today are Go and TypeScript/JavaScript only. The
planned dogfood rule (`module_graph` + `resolved_imports` over this crate’s
`crate::` edges) cannot observe Rust module edges without a Rust language
adapter. Inventing a dual non-`module_graph` path was rejected.

## What waits

Layering enforcement returns when a Rust frontend exists (language-frontend /
registry work — W2.6 territory). Until then, do not add a placeholder rule,
fake capability, or CI green-check that pretends Rust edges are analyzed.
