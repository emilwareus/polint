<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source files -> AnalysisDb | Untrusted repository source text becomes source and syntax facts with metadata. |
| Cache restore -> AnalysisDb | Cached parser facts are restored into current-run fact vectors and must receive current-run metadata. |
| Internal metadata -> SDK facts | Metadata must not cross into public SDK or runner contracts in this phase. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01-01 | Spoofing | `FactMeta.producer_id` | mitigate | Use exact provider ids from `analysis_kernel/provider.rs`: `polint.source`, `polint.go.syntax`, and `polint.ts.syntax`; tests assert these strings. |
| T-21-01-02 | Tampering | `stable_key_from_parts` | mitigate | Sort labels, normalize path separators, length-prefix labels/values, and test determinism so input order cannot alter identity. |
| T-21-01-03 | Information Disclosure | metadata accessors | mitigate | Keep metadata module and accessors crate-private/test-only; do not add SDK, runner, crate-root public, or CLI exposure. |
| T-21-01-04 | Denial of Service | metadata payload digests | accept | Digests are computed once per existing fact from small normalized fields; no unbounded recursion or source cloning is introduced. |
</threat_model>
