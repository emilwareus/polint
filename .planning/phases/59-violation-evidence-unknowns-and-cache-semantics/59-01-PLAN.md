# Phase 59-01 Plan: Policy Evidence Schema and Query Digests

## Goal

Make every v1.4 policy query diagnostic carry one normalized evidence header
while preserving existing query-specific evidence keys and the current public
rule-authoring syntax.

## Tasks

1. Add internal policy query labels and a preview policy-query version constant.
2. Add deterministic query digest helpers for `EventPattern`, `ReachQuery`,
   `GuardQuery`, `LifecycleQuery`, and `FlowQuery`.
3. Extend `PolicyViolation` construction so each violation knows its query kind
   and query digest.
4. Update `PolicyViolation::diagnostic` to emit common evidence:
   `policy_query`, `policy_query_version`, `query_digest`, `policy_status`, and
   `policy_precision`.
5. Centralize result sorting and deduplication for policy query outputs.
6. Update unit tests for events, calls, control-flow, and data-flow diagnostics
   to assert the normalized evidence header and query digest stability.
