# Phase 59-02 Plan: Policy Unknown and Budget Visibility

## Goal

Make policy capability unknown inspection visible and actionable without
exposing provider rows, raw graph IDs, or private stable keys through public
outputs.

## Tasks

1. Extend `analysis/unknown_taxonomy/collect.rs` so public policy capabilities
   route to backed unknown collectors where facts exist.
2. Map `events`, `calls`, and `control_flow` unknowns from refined call/call
   status rows into public unknown rows.
3. Map `dataflow` unknowns from data-flow edge status, data-flow budget rows,
   and evidence unknown rows into public unknown rows.
4. Preserve unsupported rows for reserved raw capabilities such as `cfg`,
   `call_graph`, and row-sampling-only surfaces.
5. Update CLI tests for `polint unknowns --cap dataflow --format json` and
   `polint inspect unknowns --cap dataflow --format json`.
6. Add unit tests that policy unknown rows are normalized, cap-filtered, and do
   not expose provider internals in compatibility outputs.
