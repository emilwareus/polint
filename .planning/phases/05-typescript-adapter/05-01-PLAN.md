<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repository TS/JS source to Oxc parser | Untrusted local source text is parsed into AST nodes and parser diagnostics. |
| Oxc diagnostics to polint diagnostics | Third-party parser diagnostics are converted into user-visible `parser/ts` diagnostics and exit-status inputs. |
| TS adapter to core DB | Adapter-provided spans and fact values enter shared `AnalysisDb`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-01 | Denial of Service | `polint_ts::parse_ts_file` | mitigate | Malformed source must not panic; `parsed.errors` and `parsed.panicked` produce diagnostics and return normally. |
| T-05-01-02 | Tampering | Oxc-to-core span conversion | mitigate | Convert ranges through `span_from_byte_range` and cover `span_from_oxc` with unit tests. |
| T-05-01-03 | Information Disclosure | `parser/ts` diagnostics | accept | Diagnostics expose only local relative file paths, line/column ranges, and syntax-error messages from local source analysis. |
| T-05-01-04 | Spoofing | SourceType selection | mitigate | Use `SourceType::from_path(&file.path).unwrap_or_default()` so TSX/JSX parsing follows the file extension instead of source text heuristics. |
</threat_model>
