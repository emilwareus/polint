<objective>
Wire validated extension providers into the analysis kernel with metadata validation and precision ceilings.

Purpose: Extension facts must become first-class internal provider output while preserving existing public API discipline and preventing unvalidated or over-precise extension rows from affecting analysis.

Output: The kernel can execute extension providers, collect provider output metadata/cache stats, merge accepted facts, retain rejected audit rows, and validate extension metadata.
</objective>
