<objective>
Add the crate-private extension manifest and discovery foundation for repo-local Rust provider extensions.

Purpose: Before any extension process is run, polint needs deterministic local discovery, manifest declarations, activation status vocabulary, and extension digest inputs that participate in the kernel input snapshot.

Output: `.polint/extensions/*/Cargo.toml` discovery is represented as typed internal extension components with stable digests, and no extension still records the existing absent sentinel.
</objective>

    Add discovery for `.polint/extensions/*/Cargo.toml` only. Normalize paths relative to the repo root, sort extension crates by relative path, read bounded manifest/source/dependency files, and compute extension source/dependency digests using `DigestKind::ExtensionCode`. Do not fetch remote code, execute cargo, or inspect network state. Include `Cargo.toml`, `Cargo.lock` when present, and `src/**/*.rs` files in deterministic digest input. Missing `.polint/extensions` should return an empty discovery set without diagnostics.
  </action>
  <acceptance_criteria>
    - Discovery only searches under `.polint/extensions/` and only accepts checked-in local paths.
    - A unit test proves two discovered extensions are returned in deterministic path order.
    - A unit test proves changing a source file changes the extension code digest.
    - A unit test proves no extension directory returns an empty list and no panic.
  </acceptance_criteria>
