## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| child process -> Rust client | The sidecar is a separate executable and its stdout/stderr are untrusted until validated. |
| timeout/cancellation -> OS process table | Failure to clean up leaks child processes beyond `polint check`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-02-01 | Spoofing | NDJSON schema | mitigate | Reject unsupported schema and unknown frame kinds before accepting rows. |
| T-46-02-02 | Tampering | Partial output | mitigate | Require an explicit `session_end` terminator with summary counts. |
| T-46-02-03 | Denial of Service | Hanging sidecar | mitigate | Enforce timeout/cancellation and kill/wait cleanup. |
| T-46-02-04 | Information Disclosure | stderr diagnostics | mitigate | Include enough stderr for diagnosis without copying source content beyond bounded error text. |
</threat_model>
