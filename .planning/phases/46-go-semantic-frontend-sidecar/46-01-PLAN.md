## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository source -> Go toolchain | Untrusted repository Go code and module files are loaded by official Go tooling. |
| Go sidecar output -> Rust client | NDJSON rows become trusted only after schema, path, and terminator validation in later plans. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-01-01 | Tampering | Sidecar identity rows | mitigate | Use official package/object/SSA identities and deterministic sorting; never benchmark-only names. |
| T-46-01-02 | Denial of Service | Package loading | mitigate | Keep `-mod=readonly`, lifecycle-scoped package patterns, and row streaming; timeout enforcement lands in Plan 02. |
| T-46-01-03 | Repudiation | Unsupported semantic constructs | mitigate | Emit explicit unsupported rows with reasons instead of silently dropping or fabricating facts. |
| T-46-01-04 | Spoofing | Sidecar schema | mitigate | Use a distinct `polint-go-semantic-1` schema and binary name. |
</threat_model>
