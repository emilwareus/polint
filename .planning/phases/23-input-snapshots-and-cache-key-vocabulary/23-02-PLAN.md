<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem -> InputSnapshot | Mutable repo files and lifecycle manifests are normalized into a coherent run snapshot. |
| Source text -> snapshot JSON | Source content influences digests but raw text must not be serialized into test/debug snapshots. |
| Language lifecycle -> cache identity | Go and TS/JS lifecycle config must be explicit so setup gaps do not look like exact inputs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-02-01 | Information Disclosure | `FileSnapshot` | mitigate | Serialize only `relative_path`, `language`, `source_text_digest`, `size_bytes`, and deterministic hint presence; never serialize raw source or `SourceFile.path`. |
| T-23-02-02 | Tampering | lifecycle digest lists | mitigate | Sort all discovered lifecycle files and source-set rows before digest construction. |
| T-23-02-03 | Spoofing | unsupported official tool input | mitigate | Record `go.tool_invocation` and `ts_js.tool_invocation` as `Unsupported` when no tool was invoked, avoiding false exactness. |
| T-23-02-04 | Repudiation | setup-missing lifecycle state | mitigate | Represent Go files outside module roots as `SetupMissing` input components with root-relative paths. |
</threat_model>
