# Phase 57-01 Plan: Control-Flow Query Internals

## Goal

Add the private query machinery needed for `ControlFlow<'_>` without widening the
public SDK beyond the already-reviewed typed query structs.

## Tasks

1. Add private `GuardPattern` accessors in `sdk/policy.rs`.
2. Change `ControlFlow<'_>` in `sdk/facts.rs` from preview panic wrappers to
   thin calls into `policy_queries`.
3. Build an internal ordered call-event projection in `policy_queries.rs`:
   refined edge plus call-site evidence, same-function grouping, target
   candidates, status/precision/confidence labels, and CFG operation-order
   fallback.
4. Implement `missing_guard` for call event plus `GuardPattern::call_any`.
5. Add focused unit tests for missing guard, satisfied guard, unsupported event
   family no-result behavior, and `max_paths` budget evidence.
