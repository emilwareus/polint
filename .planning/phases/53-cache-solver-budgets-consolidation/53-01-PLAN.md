## Trust Boundaries

| Cache helper to public API | Internal dependency metadata could become public API. | Keep ledger `pub(crate)` or test-only and run public leak gate. |
| Ledger to provider recipes | A parallel ledger could drift from production digest code. | Tests call or reconstruct production helpers and fail on mismatch. |
| Algorithm versioning | Behavior changes could reuse stale caches. | Pin explicit schema/algorithm labels in locked parts-list tests. |
