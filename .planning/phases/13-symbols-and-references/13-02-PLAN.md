<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source/module metadata -> stable key builder | Repository-controlled paths, names, and spans become ID inputs. |
| provider drafts -> AnalysisDb facts | Language modules submit normalized drafts that become public SDK facts. |
| internal query helpers -> SDK tests | Internal indexes are exercised without becoming public API. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-02-01 | Tampering | `stable_id.rs` | mitigate | Length-prefix every stable-key part before hashing and test that part-boundary changes alter IDs. |
| T-13-02-02 | Repudiation | collision diagnostics | mitigate | Builder records stable key debug input and emits deterministic diagnostics for incompatible duplicate IDs. |
| T-13-02-03 | Information Disclosure | stable key debug fields | mitigate | Store normalized path/name/span metadata only; tests reject raw source snippets in stable keys. |
| T-13-02-04 | Denial of Service | builder/query ordering | mitigate | Use BTree collections and deterministic finish passes; no per-query reparsing or graph database creation. |
</threat_model>
