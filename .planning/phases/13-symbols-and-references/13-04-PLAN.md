<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository TS/JS source -> Oxc parser/semantic | Untrusted source text is parsed and analyzed. |
| Oxc semantic internals -> polint facts | Tool-local IDs and AST nodes are normalized into public facts. |
| module graph facts -> cross-file symbol links | Resolved import state influences reference targets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-04-01 | Tampering | Oxc ID normalization | mitigate | Stable keys derive from normalized file/name/scope/span inputs; Oxc IDs never leave `symbol_graph::ts`. |
| T-13-04-02 | Information Disclosure | TS stable keys and diagnostics | mitigate | Do not store full source snippets or raw AST dumps in facts, diagnostics, or stable keys. |
| T-13-04-03 | Denial of Service | TS semantic extraction | mitigate | Run extraction only for TS-family files when symbols/references are requested and borrow `SourceFile.source` instead of cloning full files. |
| T-13-04-04 | Spoofing | module-linked import aliases | mitigate | Mark cross-file import alias links as `ModuleLinked` and emit Ambiguous/Unresolved states when target exports are not unique and proven. |
</threat_model>
