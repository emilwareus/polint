<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository Go source/build files -> Go sidecar | Untrusted repository code and module metadata are loaded by Go tooling. |
| Rust engine -> external process | polint invokes `go run` and consumes JSON output. |
| sidecar JSON -> public SDK facts | Sidecar output is validated and normalized into public symbol/reference facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-05-01 | Elevation of Privilege | `Command::new("go")` sidecar invocation | mitigate | Use fixed argument arrays, no shell, `current_dir(root)`, `env_remove("GOFLAGS")`, and no repository-provided program path. |
| T-13-05-02 | Tampering | sidecar JSON path fields | mitigate | Validate schema version and normalize all sidecar paths back to existing AnalysisDb FileIds; reject absolute/repo-escaping paths. |
| T-13-05-03 | Information Disclosure | sidecar output | mitigate | Sidecar emits spans, names, package/object keys, and diagnostics only; tests reject full source text fields. |
| T-13-05-04 | Denial of Service | Go package loading | mitigate | Run sidecar only for requested symbol/reference capabilities and configured package patterns; avoid dependency syntax loading beyond requested package modes. |
| T-13-05-05 | Repudiation | setup failures | mitigate | Setup-missing diagnostics include capability, language, reason, hint, docs path, and package path when available. |
</threat_model>
