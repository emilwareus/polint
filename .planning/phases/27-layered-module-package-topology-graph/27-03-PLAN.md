<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository JSON/text -> topology facts | package.json, package-lock.json, workspace files, lockfiles, and tsconfig files are untrusted repository inputs. |
| package-manager evidence -> precision labels | Lockfile presence must not be represented as exact dependency resolution unless parsed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-03-01 | T | package.json/package-lock parsers | mitigate | Use `serde_json`, return unsupported rows for malformed data, and never panic on unknown fields. |
| T-27-03-02 | I | package-manager private blobs | mitigate | Store normalized names, versions, schema labels, and source paths only; do not store raw lockfile bodies. |
| T-27-03-03 | S | unsupported lockfile exactness | mitigate | Mark pnpm/Yarn/Bun lockfile recognition as `Unsupported` evidence until parsed; only package-lock parsed rows use `ExactLockfile`. |
</threat_model>
