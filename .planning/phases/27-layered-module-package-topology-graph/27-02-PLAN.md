## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository files -> manifest parser | `go.mod`, `go.work`, and `go.sum` are untrusted repository text. |
| lifecycle config -> root selection | `[languages.go].module_roots` can contain invalid or escaping paths. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-02-01 | T | Go root normalization | mitigate | Reuse `GoAnalysisConfig` normalization and reject/mark setup-missing roots that escape the repository. |
| T-27-02-02 | D | Go manifest parsing | mitigate | Static parsers return unsupported topology rows for malformed directives and never panic. |
| T-27-02-03 | I | Go lifecycle files | mitigate | Do not write checked-in `go.work`; use only existing temporary lifecycle behavior from `go/lifecycle.rs`. |
</threat_model>
