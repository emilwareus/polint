<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation |
|----------|------|------------|
| TS source facts to solver edges | Unsupported dynamic JS could be converted into false positive call edges. | Consume only stable Phase 45 facts and `TokenFlowRequired` cases; leave property/prototype/this/native behavior unresolved. |
| Token-set growth | Token explosion can cause memory or CPU denial of service. | Enforce per-variable, per-callsite, and worklist caps; collapse to sentinel and emit `BudgetExceeded`. |
| Solver cache | Cached output could hide changed token budgets or input facts. | Fold JS budget knobs and every consumed upstream digest into solver digests. |

## STRIDE Notes

- Tampering: all edge provenance includes sorted contributing facts, so deleting an input fact changes edge identity.
- Denial of service: finite caps and monotonic sentinel state bound the fixpoint.
- Spoofing: no synthetic callable identity is accepted unless it maps to an existing TS inventory/semantic graph function identity.
</threat_model>
