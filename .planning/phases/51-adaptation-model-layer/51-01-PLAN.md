<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation |
|----------|------|------------|
| Repo-local model files | A broad or oracle-shaped model can flood recall. | Validate concrete patterns, reject answer-key-like RHS values, enforce expansion budgets. |
| Semantic identity | Display strings can collide or drift across runs. | Compose existing stable semantic graph identities and sorted model keys. |
| Cache correctness | Model changes can be missed by graph/solver caches. | Digest normalized model files, validation results, validator version, and budget knobs. |

## STRIDE Notes

- Tampering: model file changes must alter deterministic digests.
- Information disclosure: oracle-like labels are rejected before lowering.
- Denial of service: model expansion caps produce explicit budget evidence.
</threat_model>
