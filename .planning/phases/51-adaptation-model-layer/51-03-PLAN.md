<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation |
|----------|------|------------|
| Adaptation agent inputs | Agent can see benchmark answers and overfit. | Sandbox excludes oracle paths and prompt sanitizer fixture asserts no path/content leak. |
| Benchmark report | Recall gains can hide false positives. | Report precision deltas, new false positives, unknown deltas, and held-out deltas together. |
| Changed artifacts | Reports can omit behavior-affecting model edits. | Require changed model file digests and cache invalidation scope. |

## STRIDE Notes

- Information disclosure: forbidden oracle files never enter the prompt or sandbox.
- Repudiation: records include prompt hash, changed file digests, commands, and report paths.
- Tampering: changed model files are digest-checked and reported.
</threat_model>
