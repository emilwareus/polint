<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation |
|----------|------|------------|
| Accepted model facts | Accepted facts can bypass normal analysis precision. | Lower only validated facts with provenance, confidence, language, and scope. |
| Solver cache | Accepted model inputs can affect derived edges without invalidating caches. | Digest accepted rows, model budgets, and algorithm version in graph/solver keys. |
| Public API | Internal model/provenance types could leak to rule authors. | Keep `pub(crate)` and run `public_surface_leak` unchanged. |

## STRIDE Notes

- Spoofing: language/scope validation prevents cross-language target spoofing.
- Tampering: model-derived cache keys change with behavior-affecting model edits.
- Information disclosure: rejected/oracle-shaped model facts remain out of graph and solver output.
</threat_model>
