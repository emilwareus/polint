# Phase 60-02 Plan: Generated Fixtures and Template Smoke Tests

## Goal

Make every flagship template produce useful fixture cases under
`.polint/tests/rules/` so the local policy loop is testable immediately.

## Tasks

1. Generate positive and negative fixture source files tailored to each template
   and selected language focus.
2. Generate expected diagnostics for negative fixtures with template-specific
   message fragments.
3. Prove representative data-flow templates produce real diagnostics in temp
   repos through `polint test --format json`.
4. Prove calls and control-flow templates compile and report expected policy
   diagnostics for Go fixtures.
5. Keep all generated fixtures small and transparent enough for users to edit.
