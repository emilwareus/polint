<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| checked-out repo → perf runner | Untrusted repo source + git history read during check/review measurement |
| git ref (review_ref) → git binary | Diff base string passed to `git diff` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-63-02-01 | Tampering | changeset_for_ref review_ref argument | mitigate | Reuse existing crate::git::changeset_for_ref, which passes refs as fixed positional args to the git binary (no shell); the ref is developer/manifest-supplied, not repo-controlled. No new shell invocation is added. |
| T-63-02-02 | Elevation | workspace path resolution during measurement | mitigate | Reuse safe_join_workspace / the existing config-load workspace root; no new path joining that could escape the repo root. |
| T-63-02-03 | Denial of Service | measuring a large repo consumes host memory | accept | Intended workload; the run uses the capability-gated kernel pipeline (PERF-01) and records budget-exhaustion counters rather than unbounded expansion. |
| T-63-02-04 | Information Disclosure | curve JSON / report leaking absolute host paths | mitigate | CurvePoint keys by repo_id, not absolute paths; report rendering emits repo_id and relative fields only (asserted by test — no "/Users/" or "/home/" in output). |
</threat_model>
