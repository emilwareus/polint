<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Disk -> layer cache store | Untrusted cache manifests and payloads under `.polint/cache/layers` are read into trusted in-memory facts only after validation. |
| Cache paths -> filesystem | Digest-derived filenames and managed cache roots must prevent path traversal and symlink escape. |
| Layer cache internals -> public surface | Cache manifest/index vocabulary must remain crate-private and absent from SDK, runner, CLI, docs, and public JSON. |
| Change classification -> reuse | Conservative invalidation decisions determine whether stale data can be reused. |
| Disabled cache config -> cache store | Disabled cache mode must bypass reads and writes without filesystem access while still producing deterministic stats. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01-01 | Tampering | `LayerCacheStore::read_json` | mitigate | Validate manifest schema, `LayerKey`, payload digest, optional post-deserialize output-digest callback, and deserialize result before `Hit`; stale or corrupt entries are `InvalidEvicted`/`Miss`, and the hit outcome supplies the cached `output_digest`. |
| T-24-01-02 | Tampering | cache path construction | mitigate | Use digest-named files under `CacheLayout::layer_cache_dir()`, reject path separators in digest filenames, and do not follow user-provided manifest paths. |
| T-24-01-03 | Information Disclosure | `LayerCacheManifest` serialization | mitigate | Persist normalized metadata and payloads only; tests grep against raw source text, absolute paths, timestamps as identity, temp roots, and run IDs. |
| T-24-01-04 | Denial of Service | corrupt on-disk cache | mitigate | Deserialization failures and missing payloads are counted as invalid reads/misses and recomputed, not propagated as normal-run panics. |
| T-24-01-05 | Elevation of Privilege | public API leakage | mitigate | Keep all layer-cache/index/change types `pub(crate)` or private and verify no crate-root, SDK, runner, CLI, or documented JSON exposure. |
| T-24-01-06 | Spoofing | dependency index schema | mitigate | Store `DEPENDENCY_INDEX_SCHEMA`; mismatched or unsupported schemas cause rebuild/drop rather than trusted reuse. |
| T-24-01-07 | Tampering | invalidation planner | mitigate | Unknown, lifecycle, provider/schema, model, extension, and missing dependency changes fail closed to recompute/drop. |
| T-24-01-08 | Information Disclosure | absolute source leakage | mitigate | Manifest tests must reject absolute temp roots and source bodies in persisted metadata. |
| T-24-01-09 | Repudiation | disabled cache bypass | mitigate | Disabled layer-cache reads/writes return explicit bypass statuses and providers record `CacheStats::bypasses_disabled` instead of silent misses. |
</threat_model>
