<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation |
|----------|------|------------|
| Provider facts to taxonomy rows | Aggregation could hide real diagnostics or precision states. | Taxonomy is read-only normalization; providers keep real facts/diagnostics. |
| Public JSON stability | Category churn could break agent consumers. | Stable labels, schema tests, and deterministic ordering. |
| Audit trail | Resolved unknowns could be erased from deltas. | Preserve baseline/current row keys for comparison. |

## STRIDE Notes

- Repudiation: taxonomy rows carry source stable keys and provider/family.
- Information disclosure: no absolute temp paths or private oracle paths in rows.
- Denial of service: aggregation sorts bounded in-memory rows and does not run new analysis.
</threat_model>
