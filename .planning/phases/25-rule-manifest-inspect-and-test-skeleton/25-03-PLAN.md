<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Fixture files -> temp repo | User-owned fixture files are copied into temporary repositories before analysis. |
| Rule host -> fixture runner | The runner executes user-owned Rust rule hosts and parses their JSON output. |
| Temp paths/cache -> public test JSON | Machine-local paths and cache directories must not become stable test output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-03-01 | Tampering | fixture copy | mitigate | Copy only fixture-owned files, skip `polint-test.toml`, and reject path traversal when materializing temp repos. |
| T-25-03-02 | Spoofing | child check JSON | mitigate | Parse output as public `PolintReport` JSON before matching diagnostics. |
| T-25-03-03 | Information Disclosure | test report JSON | mitigate | Normalize diagnostics and omit temp roots, cache paths, durations, Cargo target paths, raw source text, and internal run reports. |
| T-25-03-04 | Denial of Service | failing rule host | mitigate | Treat nonzero child process status as a case failure with deterministic error text, not a panic. |
| T-25-03-05 | Repudiation | diagnostic mismatch | mitigate | Report expected vs observed mismatch by rule, case, rule id, file, severity, and message/range matcher. |
</threat_model>
