<threat_model>
ASVS L1 posture: no high severity threat is accepted; mitigated threats use deterministic merge order and bounded parallel work.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rayon worker -> main analysis database | Worker-produced parse results merge into shared `AnalysisDb`. |
| filesystem order -> deterministic IDs | Walk order can vary; sorted discovery must control IDs. |
| parallel rule execution -> diagnostics | Rule diagnostics from multiple workers are deduped and sorted before output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-01 | Tampering | parallel fact merge | mitigate | Merge worker results only by sorted `FileId`; never mutate `AnalysisDb` concurrently. |
| T-07-03-02 | Denial of Service | Rayon parsing | mitigate | Use existing Rayon global pool and per-file units; do not spawn unbounded threads manually. |
| T-07-03-03 | Repudiation | nondeterministic diagnostics | mitigate | Keep dedupe/sort after rule execution and add repeated-run output tests. |
| T-07-03-04 | Information Disclosure | worker payloads | accept | Workers only handle local source already loaded for analysis; no new external sink is introduced. |
</threat_model>
