<threat_model>
ASVS L1 posture: no high severity threat is accepted; mitigated threats use conservative invalidation, source-free payloads, and fallback behavior.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parser output -> `.polint/cache` | Parser diagnostics and facts are serialized to local JSON. |
| `.polint/cache` -> `AnalysisDb` | Cached facts re-enter the analysis database on later runs. |
| current run IDs -> cached IDs | IDs stored in cache may not be valid for the current run unless remapped. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Tampering | cached fact JSON | mitigate | Treat invalid JSON as a miss and remap IDs through `AnalysisDb` push APIs before use. |
| T-07-02-02 | Information Disclosure | cache payloads | mitigate | Cache only fact metadata and diagnostics; tests assert no `source`, `ast`, or `tree` payload fields. |
| T-07-02-03 | Denial of Service | stale cache entries | mitigate | Include relative path, content hash, config hash, rule hash, cache version, and language schema in keys. |
| T-07-02-04 | Spoofing | parser diagnostics from cache | mitigate | Store diagnostics only under content-addressed keys and preserve parser rule IDs (`parser/go`, `parser/ts`). |
</threat_model>
