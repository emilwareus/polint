<threat_model>
ASVS L1 posture: no high severity threat is accepted; mitigated threats use local validation, deterministic behavior, and bounded cache contents.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository files -> cache key | File paths, file contents, and config values influence cache IDs. |
| `.polint/cache` -> analysis process | Cache JSON is local mutable data and may be stale or malformed. |
| CLI flags -> cache behavior | `--no-cache` must control whether cache reads/writes happen. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01-01 | Tampering | `.polint/cache/*.json` | mitigate | Add `read_json_or_miss` so malformed cache files become misses, not trusted analysis data. |
| T-07-01-02 | Information Disclosure | cache values | mitigate | This plan only creates key/helpers and tests; later payload plans must store metadata only and no source text. |
| T-07-01-03 | Denial of Service | cache key collisions | mitigate | Include relative path, content hash, config hash, rule hash, version, and schema in stable IDs. |
| T-07-01-04 | Repudiation | disabled cache behavior | mitigate | Add CLI and cache unit tests proving disabled writes create no `.polint/cache` directory. |
</threat_model>
