<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| solver results -> AnalysisDb | Computed facts become shared internal state for later providers. |
| input snapshot/cache identity -> provider reuse | Missing digest inputs could cause stale domain facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-03-01 | T | `DomainStore` | mitigate | Normalize rows deterministically, refresh metadata on replace, and preserve explicit status/reason payloads for later validation. |
| T-31-03-03 | R | provider output metadata | mitigate | Kernel run report records provider id, schema, output digest, and cache stats for `polint.abstract_domains`. |
| T-31-03-04 | T | layer key | mitigate | Cache identity includes domain versions, schema, reduction/widening policy, semantic MIR/CFG/calls digests, config/lifecycle, and absent model/toolchain/extension slots. |
| T-31-03-05 | E | public boundary | mitigate | Provider remains crate-private with no SDK, CLI, runner, README, or docs/facts changes in this plan. |
</threat_model>
