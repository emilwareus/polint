# Phase 62-02 Plan: Deterministic Flagship Template Gate

## Goal

Add and run a deterministic repeated-run check for generated flagship policy
templates.

## Tasks

1. Add a CLI integration test that generates representative flagship templates
   in a temp repo.
2. Run `polint test --no-cache --format json` twice against the generated rule
   pack.
3. Assert stable case statuses and diagnostic payloads across both runs.
4. Keep the test external-user shaped: generated `.polint/rules`, public SDK
   imports, and no internal modules.

## Verification

- `cargo test -p polint --test cli new_rule_policy_templates_are_deterministic --locked`
- `cargo test -p polint --test cli new_rule_policy_template --locked`
