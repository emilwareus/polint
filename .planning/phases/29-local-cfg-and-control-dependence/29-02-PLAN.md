<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| language lowerers -> shared builder | Language-specific code must not bypass common ordering, IDs, and edge semantics. |
| CFG facts -> derived analyses | Derived facts must be computed from selected graph views, not ad hoc language-specific assumptions. |
| synthetic exits -> precision claims | Postdominance depends on exit policy and must not claim exactness for unsupported exits. |
