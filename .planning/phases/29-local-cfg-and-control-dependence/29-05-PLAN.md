## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Oxc/MIR -> CFG | Oxc parser data must be consumed only locally and must not become CFG identity or public output. |
| dynamic JS -> precision labels | Dynamic language behavior must not be labeled exact when only syntax/MIR evidence exists. |
| async/cleanup -> local CFG | Scheduler-level and impossible finally paths must not become misleading local CFG edges. |
