<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| benchmark metadata -> report | Imported competitor claims must not be confused with locally reproduced results. |
| adaptation prompt -> benchmark score | Adapted results must preserve the prompt and inputs that produced them. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T40-01 | Spoofing | competitor records | Mitigated | Store product/version/source/reproduction status explicitly. |
| T40-02 | Repudiation | adaptation runs | Mitigated | Hash prompt text and changed rule/extension files. |
| T40-03 | Information Disclosure | suite paths | Mitigated | Normalize paths and keep local clone paths out of public claims unless intentional. |
</threat_model>
