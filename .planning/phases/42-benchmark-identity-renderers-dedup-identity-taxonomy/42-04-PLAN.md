<objective>
Install the v1.3 public-surface-leak CI gate that every subsequent phase (43–54) inherits. The gate is a workspace integration test at `tests/public_surface_leak.rs` that compiles a tiny probe crate at `tests/fixtures/public-surface-leak-probe/` consisting of `#![no_implicit_prelude]` + `use polint::sdk::prelude::*;` + witness expressions for the v1.0–v1.2 allow-list, then asserts ZERO identifiers from `polint::analysis::*` (Plans 01–03 of this phase) or any other private namespace are reachable through the glob. Wire the test into fast CI on Linux AND macOS — both platforms must pass independently (D-18). The locked `ALLOWED_PRELUDE` list inside `tests/public_surface_leak.rs` becomes the source of truth Phases 43–54 must extend deliberately to ship any new public type (D-19).

Purpose: Phase 42 is the phase that institutes the leak gate. The identity records (Plan 01), renderers (Plan 02), and identity taxonomy (Plan 03) all stay `pub(crate)` by design — the gate is the enforcement mechanism that makes that promise mechanical instead of aspirational. Without this gate, a single accidental `pub` slip on a v1.3 solver type silently leaks into the supported SDK and we ship a semver liability we can't take back. With this gate, every PR that mutates visibility runs into a compile error if it touches the public surface.

Output: One new workspace integration test (`tests/public_surface_leak.rs`), one new probe crate (`tests/fixtures/public-surface-leak-probe/{Cargo.toml,src/lib.rs}`), a `[workspace] exclude = [...]` entry in the root `Cargo.toml` to keep the probe out of normal builds, and a CI workflow step that runs the gate on Linux + macOS.
</objective>
