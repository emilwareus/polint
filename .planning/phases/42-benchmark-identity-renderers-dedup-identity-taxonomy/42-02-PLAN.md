## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source file text | `SourceFile.text` crosses from the v1.2 source-loader (already validated) into the Jelly renderer's CRLF normalization step. The renderer is read-only — it never mutates `SourceFile.text`. |
| Workspace-relative paths | `SourceFile.relative_path` crosses into the renderer's output string. The renderer forward-slash-normalizes (`replace('\\', "/")`) but does NOT canonicalize / resolve / dereference symlinks — all path operations stay string-only. |
| Renderer output → JSON report | Renderer output strings flow into the eval report JSON via `jelly_oracle_coverage.unmatched[*].span`. Strings are deterministic byte-for-byte across platforms (D-25). |
| Eval JSON consumers | v1.2 downstream tooling reads the `MetricSections` JSON. `#[serde(default)]` extension keeps the contract additive — older readers receive new sections as defaults instead of failing. |
| Renderer cache invalidation | The renderer code-version constants (`go_relstring_v1`, `jelly_span_v1` in Plan 01's `identity_provider_parameter_digest`) cross from compile-time-static strings into the identity provider cache key. A future renderer logic change MUST bump these constants — otherwise stale cached identity records are reused. |
