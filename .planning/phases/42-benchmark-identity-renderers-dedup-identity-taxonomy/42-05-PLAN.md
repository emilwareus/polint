<objective>
Close the four feasible Phase 42 verification gaps for IDENT-02 (Go RelString
half) and IDENT-01 (dedup determinism), without exceeding the orchestrator-verified
feasible scope.

The verifier found that the Go `RelString` renderer is fed the WRONG `package_or_module`
on real records: `package_or_module_for_file` returns `db.path_for(file)` (the file path)
for every language, so real Go records render `src/main.go.Foo` instead of `pkg.Foo`.
Every renderer call site also discards its output and no provider-level test exercises a
record built by the real provider. Separately CR-03 leaves dedup's tie-break under-specified
when sort keys tie but `originating_call_site_id` differs, which Phase 43's byte-stability
gate will depend on.

This plan delivers the package-NAME qualification that is feasible against the v1.2 substrate
(PackageFact carries the Go package-clause name via `db.packages()`), bumps the cache trip-wire,
adds a real-provider test, hardens dedup determinism, removes the discarded-output smell, and
corrects the IDENT-02 overstatement in the Plan 02 summary.

Purpose: Make the Go RelString renderer correct and proven on real Go records to the extent
the current substrate allows, and make dedup output fully order-independent so the Phase 43
determinism gate can rely on it.

Output: Corrected provider Go package resolution, bumped cache version, real-provider renderer
test, hardened dedup tie-break + determinism test, asserted/documented render call sites, and
a reconciled Plan 02 summary.

OUT OF SCOPE (do NOT implement): `go/packages` integration, the Go semantic frontend/sidecar,
full module import-path resolution, wiring RelString into the Go RTA oracle scoring path
(keep the oracle key on `display_name`), broad multi-fixture Jelly coverage (Phase 45). No new
dependencies (T-42-SC). No `unsafe`. Production code stays panic-free (`unwrap`/`expect`/`panic`
only under `#[cfg(test)]`). All identity types stay `pub(crate)` (leak gate must stay green).
`MetricSummary` shape stays unchanged (layout-lock test stays green).
