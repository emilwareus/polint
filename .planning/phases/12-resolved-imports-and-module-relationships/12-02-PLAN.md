<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo files/import facts -> module graph provider | Untrusted source paths and import strings become graph records. |
| provider -> AnalysisDb | Derived facts become rule-visible SDK data. |
| config/root paths -> path normalization | User-controlled include paths and repository layout influence node labels. |
| provider diagnostics -> JSON/SARIF/human output | Resolver/setup messages become machine-readable diagnostics. |
| future Go metadata command -> provider | Plan 12-04 fills this boundary using fixed command arguments. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-02-01 | T | `module_graph::paths` | mitigate | Use lexical normalization, reject `..` above repo root, preserve `/` separators, and forbid `std::fs::canonicalize` for graph identities. |
| T-12-02-02 | R | provider execution order | mitigate | Runner and CLI tests assert provider call order between language adapters and rule execution. |
| T-12-02-03 | I | SDK relationship facts | mitigate | Store polint-owned IDs/status/reason enums only; raw resolver output stays inside `module_graph::ts` and `module_graph::go`. |
| T-12-02-04 | D | graph size and traversal | mitigate | Use deterministic vectors, direct adjacency iteration, and BFS over existing edges; no recursive unbounded traversal. |
| T-12-02-05 | E | command execution for Go metadata | transfer | This plan defines Go metadata index boundaries only; Plan 12-04 must use fixed `go list -json ./...` arguments and no shell. |
| T-12-02-06 | S | untrusted rule capability request | mitigate | Provider runs only for plan-requested `resolved_imports` or `module_graph`; support rows block unsupported states. |
</threat_model>
