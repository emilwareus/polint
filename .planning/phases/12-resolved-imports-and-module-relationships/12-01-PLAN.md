<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo-local rule crate -> macro expansion | Untrusted rule signatures select fact-view parameters that drive capability support. |
| SDK public API -> core internals | Public facts must not expose raw resolver output, `petgraph`, AST nodes, or mutable database access. |
| repo config/source -> diagnostics | User-controlled strings can appear in diagnostics and evidence. |
| future Go metadata command -> provider | Go command execution is not introduced in this plan but must be accounted for by later plans. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01-01 | S | `crates/polint-macros/src/lib.rs` fact-view path matching | mitigate | Accept only unqualified SDK view names or canonical `polint::sdk::facts::*` / `polint::sdk::prelude::*` paths; retain tests rejecting local lookalikes. |
| T-12-01-02 | T | public relationship structs in `core` and `sdk::prelude` | mitigate | Public facts use polint-owned ID newtypes and status enums only; do not expose `oxc_resolver`, `go list`, raw AST, or `petgraph` types. |
| T-12-01-03 | R | capability support rows | mitigate | Known-but-not-wired capability rows are deterministic `Unsupported` rows with `polint/capability` diagnostics so rules do not execute without facts. |
| T-12-01-04 | I | generated diagnostics/output | mitigate | Status/reason enums use fixed variant names; tests assert evidence fields rather than embedding raw resolver payloads. |
| T-12-01-05 | D | large graph query outputs | accept | This plan only defines borrowed views and small in-memory vector access; provider size controls are handled in Plan 12-02. |
| T-12-01-06 | E | Go metadata command execution | transfer | No command is executed in this plan; Plan 12-04 owns fixed-argument `go list` execution and setup diagnostics. |
</threat_model>
