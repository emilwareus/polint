    Create analysis/summaries/store.rs following the CallStore pattern from analysis/calls/store.rs (per D-03):

    SummaryOutput struct with fields: summaries: Vec of SummaryFact, events: Vec of SummaryEventFact.
    - empty() returns default.
    - normalized(mut self) -> Self sorts summaries by (stable_key, id) then reassigns IDs sequentially from 0, sorts events by (stable_key, id) then reassigns IDs.

    SummaryStore struct with:
    - output: SummaryOutput
    - summaries_by_callable: BTreeMap of String (callable_stable_key) to Vec of usize (indexes into output.summaries)
    - summaries_by_domain: BTreeMap of SummaryDomainKind to Vec of usize
    - summaries_by_function: BTreeMap of FunctionId to Vec of usize

    SummaryStore::from_output(output: SummaryOutput) -> Result of Self, AnalysisError:
    1. Normalize output.
    2. Build indexes: by callable, by domain, by function.
    3. Return Ok(store).

    Accessor methods:
    - summaries_by_callable(&self, callable_key: &str) -> Vec of &SummaryFact
    - summaries_by_domain(&self, domain: SummaryDomainKind) -> Vec of &SummaryFact
    - summaries_by_function(&self, function: FunctionId) -> Vec of &SummaryFact
    - all_summaries(&self) -> &[SummaryFact]
    - all_events(&self) -> &[SummaryEventFact]
    - summary_count(&self) -> usize
    - event_count(&self) -> usize

    Private helper: summary_refs(&self, indexes: Option of &Vec of usize) -> Vec of &SummaryFact (same pattern as CallStore::site_refs).

    Add pub(crate) mod store to summaries/mod.rs.

    Add unit tests:
    - normalized_sorts_summaries_by_stable_key_and_reassigns_ids
    - from_output_builds_deterministic_indexes
    - empty_output_builds_empty_store
    - summaries_indexed_by_callable_and_domain
