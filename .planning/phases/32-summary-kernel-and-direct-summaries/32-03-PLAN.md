    Add pub(crate) mod builder to summaries/mod.rs.

    DirectSummaryBuilder::build(db: &AnalysisDb) -> SummaryOutput:
    1. Collect all MIR bodies from db.mir_bodies(). Group by function (via body.function field).
    2. For each function with a MIR body:
       a. Build control effects by reading domain observation facts for this body (reachability slot -> DoesNotReturn evidence if all exit blocks unreachable; nilness/truthiness slots -> throw/panic evidence if deterministic). Read MIR operations for explicit return, throw, panic, process-exit operations. Read MIR body async/generator flags if available. Compose into ControlEffects.
       b. Build call effects by reading call facts for this function from db (call sites, targets, unresolved). Direct callee stable keys become direct_callees set. Unresolved call count comes from unresolved call facts. Callback evidence from MIR operation shapes (function-valued parameter passed to a call site). If function has unresolved calls, compose with join of the known effects and mark appropriately.
    3. Emit SummaryFact rows for control and call domains with: callable_stable_key from MIR body's stable key root, function ID, domain kind, status (Present if real evidence, Unknown if unresolved calls dominate), precision (Local for direct observation, SetupAware if setup-dependent), provenance NativeLocal, payload_digest from domain.stable_digest_parts(), stable_key from stable_key_from_parts.
    4. Emit SummaryEventFact for top/unknown/budget events.

    Add unit tests:
    - empty_db_produces_empty_output
    - builder_does_not_call_solver (verify by checking no solver types are imported/constructed)

    The memory and TITO builders will be in the next task to keep context manageable.

  <action>
    Extend DirectSummaryBuilder::build to compute memory effects and TITO per function (per D-07, D-09, D-10, D-11):

    Memory effects builder (per D-09):
    - For each MIR body, walk MIR operations.
    - Track AccessKind per MemoryResource: reads of places -> Read, writes -> Write, both -> ReadWrite.
    - Map place roots to MemoryResource: parameter places -> Param(index), receiver places -> Receiver, return places -> Return, local places -> Local, module/global references -> Global or Module.
    - Set may_have_external_effects = true if the function has unresolved calls, calls to known external-effect functions, or uses unsupported semantics that could have side effects.
    - Compose into MemoryEffects domain value.

    TITO builder (per D-07, D-08):
    - For each MIR body, walk MIR operations looking for:
      a. Parameter-to-return flow: a return operation whose value traces back to a parameter place through assignments/copies. Emit FlowEdge { from: Param(i), to: Return, kind: Value }.
      b. Receiver mutation: a write operation to the receiver place. Emit FlowEdge { from: Receiver, to: Receiver, kind: BySideEffect }.
      c. Argument mutation: a write to a parameter place. Emit FlowEdge { from: Param(i), to: Param(i), kind: BySideEffect }.
    - Simple tracing only: follow direct Assign/Copy/Move MIR operations, do not follow field-level access paths (per D-07, D-10 deferred).
    - Compose into DataFlowTito domain value.

    For both domains: emit SummaryFact rows with callable_stable_key, function, domain kind, status, precision, provenance, payload_digest, and stable_key. Emit SummaryEventFact for functions where unresolved calls or unsupported semantics force unknown/top.

    Add unit tests:
    - memory_effects_tracks_receiver_and_param_access
    - tito_detects_param_returned_directly
    - unresolved_calls_produce_may_have_external_effects
  </action>
