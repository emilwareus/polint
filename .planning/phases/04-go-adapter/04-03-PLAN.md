  <action>
    Update the branch helper in `crates/polint-go/src/lib.rs` so `BranchObligation.stable_fingerprint` is computed from stable source identity only: `db.path_for(file)`, function display name, `decision_span.start_line`, `decision_span.start_col`, normalized `condition_text`, and `edge_label`.     Implement conservative syntax-only error-path marking. `is_error_path` should be true when the condition text or branch subtree matches clear syntax patterns such as `err != nil`, `err == nil`, `errors.Is(err, ...)`, `errors.As(err, ...)`, condition text containing `error`, or a branch that returns an error-looking value from a function/method whose result syntax includes `error`. Keep this helper named/documented as heuristic and avoid any claim of exact coverage.

    Preserve the `GoBranchObligations` rule wording in `crates/polint-rules/src/lib.rs` unless a compile fix is required; that rule already says the check is heuristic. Do not add dynamic coverage facts or semantic Go type analysis.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-03-03 | Denial of Service | branch traversal | mitigate | Traverse parser nodes in function bodies deterministically without reparsing or cloning full source strings. |

</threat_model>
