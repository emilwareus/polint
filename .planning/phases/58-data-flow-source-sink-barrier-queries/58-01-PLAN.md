# Phase 58-01 Plan: Data-Flow Query Internals

## Goal

Back `DataFlow<'_>::forbidden(FlowQuery)` with private source, sink, and path
matching without widening the public SDK beyond the existing typed query
objects.

## Tasks

1. Add crate-private accessors for `SourcePattern`, `SinkPattern`, and
   `BarrierPattern` in `sdk/policy.rs`.
2. Change `DataFlow<'_>` in `sdk/facts.rs` from fail-closed preview behavior to
   a thin call into `policy_queries`.
3. Add private source/sink/barrier matching helpers in `policy_queries.rs`.
4. Use `analysis::data_flow::query::find_paths` with `FlowQuery::max_depth` and
   `FlowQuery::max_paths`.
5. Add focused unit tests with manual private data-flow facts for found path,
   barrier-covered path, budget cap, unknown path, and unsupported zero-result
   behavior.

## Verification

- `cargo test -p polint --lib data_flow_forbidden --locked`
- `cargo test -p polint --lib data_flow_forbidden_respects_barrier --locked`
