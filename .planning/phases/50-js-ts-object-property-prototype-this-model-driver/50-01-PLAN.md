<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation |
|----------|------|------------|
| Oxc syntax to object facts | Dynamic JS syntax could be over-interpreted as a stable object/callee. | Emit exact facts only for stable syntactic forms; computed/dynamic forms become bucketed or unsupported facts. |
| Stable object identity | Display names or TypeScript types could collide and produce false edges. | Compose stable keys from file/span/inventory/semantic identities, never names or declared types alone. |
| Semantic graph lowering | Object facts could bypass the closed constraint vocabulary. | Lower to `Alloc`, `FieldLoad`, `FieldStore`, `CopyEdge`, and `CallConstraint`; add no public object graph surface. |

## STRIDE Notes

- Tampering: semantic graph validation rejects dangling object endpoints.
- Denial of service: computed keys are bucketed here and bounded in later solver plans.
- Information disclosure: no source text or public SDK fact surface is added.
</threat_model>
