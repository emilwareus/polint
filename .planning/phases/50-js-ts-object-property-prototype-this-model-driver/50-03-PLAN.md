<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation |
|----------|------|------------|
| Property names to call targets | Name-only matching could create false positives. | Dispatch only from callable tokens stored in object property buckets with provenance. |
| Computed property buckets | Unknown keys can explode candidates or precision loss. | Exact and computed buckets stay separate; computed reads are conservative and budgeted. |
| Solver policy composition | Object policy could perturb existing Go/TS token output. | Default-disabled behavior is byte-identical; enabled output is merged and sorted under one `SolverOutput`. |

## STRIDE Notes

- Tampering: deleting a property write changes or removes derived edge stable keys.
- Denial of service: property, object, token, candidate, and worklist caps bound propagation.
- Spoofing: a callee must be an existing function semantic node, not a property string.
</threat_model>
