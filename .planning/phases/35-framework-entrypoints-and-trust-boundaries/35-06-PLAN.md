       - check_duplicate_stable_keys(diagnostics, "DispatchEdge", db.dispatch_edge_facts().iter().map(|row| row.stable_key.as_str()))
       - check_duplicate_stable_keys(diagnostics, "UnresolvedFramework", db.unresolved_framework_facts().iter().map(|row| row.stable_key.as_str()))

    3. For each EntrypointFact: check target_function references a valid FunctionId, check target_symbol (if Some) references a valid SymbolId, check registration_file references a valid FileId, check registration_span has valid byte range (start_byte <= end_byte).

    4. For each TrustBoundaryFact: check file references a valid FileId, check span, check entrypoint_stable_key exists in entrypoint facts.

    5. For each FrameworkDispatchEdgeFact: check to_target references a valid FunctionId, check to_symbol (if Some), check file, check span, check from_source is a non-empty string.

    6. For each UnresolvedFrameworkFact: check file, check span.

If any row from producer "polint.entrypoints" has precision FactPrecision::Exact, emit diagnostic "precision ceiling exceeded: framework facts must not claim Exact".

    8. Conflicting entrypoint registrations: check if multiple EntrypointFact rows point to the same target_function with different framework_ids — emit a warning diagnostic.
