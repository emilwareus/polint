<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SDK query helpers -> internal stores | Helpers must expose curated facts only, not internal stores or parser data. |
| status-aware facts -> policy diagnostics | Rules must keep precision/status visible before making claims. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T41-03 | Information Disclosure | SDK helpers | Mitigated | Return borrowed public fact types only and test public imports. |
| T41-04 | Repudiation | diagnostics from helpers | Mitigated | Docs/tests require precision/status checks for setup-sensitive facts. |
</threat_model>
