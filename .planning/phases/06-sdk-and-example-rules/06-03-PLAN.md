| Boundary | Description |
|----------|-------------|
| config -> rule behavior | User-controlled rule options choose thresholds, forbidden imports, denied strings, file globs, and allow lists. |
| source facts -> diagnostics | Repository source facts become diagnostic messages and evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-01 | Tampering | glob matching in rule file filters | mitigate | Reuse existing `globset` helper behavior and add tests for `files` and `allow_files` decisions. |
| T-06-03-02 | Information Disclosure | literal diagnostic messages | mitigate | Report only the matched literal value and specific evidence labels; do not include surrounding source snippets. |
| T-06-03-03 | Denial of Service | rule loops over facts | mitigate | Use SDK borrowed helpers and deterministic dedupe sets for raw-color overlap instead of cloning all source text. |
| T-06-03-04 | Repudiation | deterministic diagnostics | mitigate | Keep stable rule IDs, evidence labels, and ranges so findings are reproducible in snapshots and CLI JSON. |
</threat_model>
