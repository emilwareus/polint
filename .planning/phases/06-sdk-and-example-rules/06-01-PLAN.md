Current SDK and core contracts to preserve per D-01 and D-03:

```rust
pub trait Rule: Send + Sync {
    fn meta(&self) -> RuleMeta;
    fn capabilities(&self) -> Capabilities;
    fn run(&self, ctx: &mut RuleCtx<'_>) -> Result<()>;
}

pub struct RuleCtx<'a> {
    db: &'a AnalysisDb,
    diagnostics: Vec<Diagnostic>,
    rule: RuleMeta,
    options: RuleOptions,
}
```

```rust
pub mod prelude {
    pub use anyhow::Result;

}
```

<threat_model>
ASVS L1 posture: no high severity threat is accepted; mitigated threats use local validation, deterministic behavior, or bounded data exposure.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated rule template -> user repository | `polint new-rule` writes Rust source into `.polint/rules/{rule_name}` based on CLI input. |
| rule code -> analysis facts | Repo-local rules consume `RuleCtx` facts created from untrusted repository source files. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01-01 | Tampering | `rule_template` in `crates/polint-cli/src/main.rs` | mitigate | Preserve `sanitize_name` for package names and add tests that generated source contains only SDK imports and no user-controlled dependency path. |
| T-06-01-02 | Information Disclosure | `RuleCtx::source_file` | accept | Source access is local analysis data already available to rules; no network or secret store is introduced. |
| T-06-01-03 | Denial of Service | `RuleCtx` helper iteration | mitigate | Implement helpers as borrowed iterators/slices per D-05 so large fact sets are not cloned for SDK convenience. |
| T-06-01-04 | Elevation of Privilege | SDK prelude exports | accept | Prelude only re-exports local Rust types already available through workspace crates; no execution sandbox or plugin loading is added in this phase. |
</threat_model>
