# Phase 61-01 Plan: Consolidated Policy Query Docs

## Goal

Make the public documentation complete enough for rule authors to understand
the v1.4 preview policy-query surface without reading implementation code.

## Tasks

1. Add `docs/facts/policy-queries.md` covering:
   - preview status,
   - the one query-object style,
   - view-to-capability mapping,
   - `EventPattern`, `SourcePattern`, `SinkPattern`, `GuardPattern`, and
     `BarrierPattern`,
   - `ReachQuery`, `GuardQuery`, `LifecycleQuery`, and `FlowQuery`,
   - `PolicyViolation::diagnostic(...)` evidence,
   - precision/status/confidence vocabulary,
   - budget and unknown behavior,
   - template IDs and realistic usage examples.
2. Link the page from `docs/facts/README.md`, events, calls, control-flow,
   data-flow, evidence, and capability docs.
3. Keep the docs honest about unsupported preview vocabulary and heuristic
   matching.
