# Phase 61-02 Plan: External SDK Matrix Tests

## Goal

Add an explicit outside-user validation matrix for every preview policy view and
query family.

## Tasks

1. Add a temp-repo style CLI test that writes `.polint/rules`, imports only
   `polint::sdk::prelude::*`, registers through `polint::runner::run_cli`, and
   runs `polint check --format json --fail-on none`.
2. Cover:
   - `Events<'_>::matching(EventPattern::call(...))`,
   - `Calls<'_>::forbidden_reachable(ReachQuery)`,
   - `ControlFlow<'_>::missing_guard(GuardQuery)`,
   - `ControlFlow<'_>::missing_cleanup(LifecycleQuery)`,
   - `DataFlow<'_>::forbidden(FlowQuery)`.
3. Assert diagnostics and normalized policy evidence for each query family.
4. Assert no `polint/capability` diagnostics for the supported preview views.
