<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parser AST -> MIR contracts | Language parser objects must not become persistent MIR/place identity. |
| MIR/place internals -> public SDK/CLI | New analysis contracts must remain crate-private. |
| unsupported constructs -> downstream consumers | Unsupported semantics must be explicit rows, not missing data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-01-01 | I | `analysis` module visibility | mitigate | Register only `pub(crate) mod analysis;` and add no SDK, runner, crate-root public, CLI, or docs exports. |
| T-28-01-02 | T | Stable place identity | mitigate | Stable keys derive from normalized labeled parts and never from dense IDs, parser allocation IDs, temp paths, or wall-clock data. |
| T-28-01-03 | R | Unsupported semantics | mitigate | Require structured `UnsupportedSemanticFact` fields for construct, evidence, affected places/domains, conservative action, precision, and status. |
| T-28-01-04 | I | Parser AST references | mitigate | Contract tests grep MIR/place structs for `tree_sitter::Node`, Oxc AST types, Oxc spans, and raw parser lifetimes. |
</threat_model>
