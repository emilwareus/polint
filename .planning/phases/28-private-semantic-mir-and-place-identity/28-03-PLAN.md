<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tree-sitter Go AST -> MIR rows | Parser nodes and lifetimes are untrusted implementation details and must not escape. |
| Go dynamic/control constructs -> downstream analyses | Unsupported or setup-sensitive constructs must be visible as conservative rows. |
| call-shaped MIR -> direct-call phases | Calls are shape evidence only, not target resolution or call graph facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-03-01 | I | Go lowering output | mitigate | Contract grep checks ensure emitted MIR/place row structs do not contain tree-sitter node or lifetime types. |
| T-28-03-02 | T | Go multi-assign/projection writes | mitigate | Emit explicit `AssignMode::Simultaneous` and `ProjectionMutation` rather than treating them as simple overwrites. |
| T-28-03-03 | R | Unsupported Go semantics | mitigate | Emit structured `UnsupportedSemanticFact` rows for goroutines, defer, select, channels, panic/recover, unsafe, reflection, and parser recovery. |
| T-28-03-04 | E | Direct-call overreach | mitigate | Keep call rows as `MirOperationKind::Call` only; no direct target facts, call indexes, or public graph views are added. |
</threat_model>
