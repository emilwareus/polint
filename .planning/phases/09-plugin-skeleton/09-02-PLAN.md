<threat_model>
ASVS L1 posture: no high severity threat is accepted; plugin manifest loading must fail closed and produce auditable local errors.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest file -> host | Local JSON manifest controls plugin component path and metadata. |
| filesystem -> plugin host | Host validates component path existence before future loading. |
| wasm bytes -> Wasmtime | Optional feature validates bytes as a component without executing it. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02-01 | Tampering | plugin manifest | mitigate | Validate required metadata fields and parse failures with typed errors. |
| T-09-02-02 | Spoofing | component path | mitigate | Resolve relative paths against manifest directory and fail if the component file is missing. |
| T-09-02-03 | Denial of Service | invalid component bytes | mitigate | Add feature-gated Wasmtime validation test for invalid bytes; do not execute components. |
| T-09-02-04 | Elevation of Privilege | plugin execution | mitigate | Keep this plan validate-only; do not instantiate or run plugin rules. |
</threat_model>
