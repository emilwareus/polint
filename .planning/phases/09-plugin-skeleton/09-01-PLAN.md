## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host facts -> plugin | Plugin code can request specific host-owned facts through stable IDs. |
| plugin -> diagnostics | Plugin code reports diagnostics through host-owned typed payloads. |
| WIT contract -> future runtime | Future runtime implementation will depend on these names and shapes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01-01 | Information Disclosure | host fact API | mitigate | Keep host queries narrow and stable-ID based; add tests proving no AST/source payload contract names. |
| T-09-01-02 | Tampering | diagnostic report API | mitigate | Use a typed diagnostic record instead of loose positional fields. |
| T-09-01-03 | Repudiation | plugin metadata | mitigate | WIT exports typed metadata and capabilities so host can audit plugin identity later. |
| T-09-01-04 | Elevation of Privilege | plugin runtime | mitigate | Do not add execution or scheduling APIs in this plan. |
</threat_model>
