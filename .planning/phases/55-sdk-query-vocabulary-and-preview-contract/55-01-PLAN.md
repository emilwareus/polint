<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SDK prelude -> external rule crates | Every re-export becomes a public rule-authoring contract. |
| policy vocabulary -> private analysis engine | Public query structs must not freeze raw graph, solver, provider, parser, or private ID internals. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T55-01 | Information Disclosure | SDK fact-view structs and policy types | Mitigated | Keep fields private where they point at analysis state and expose only typed, string/list-based policy vocabulary. |
| T55-02 | Tampering | Public API shape | Mitigated | Use one constructor style and explicit prelude exports so downstream phases cannot accidentally support competing DSLs. |
</threat_model>
