<threat_model>

| Boundary | Description |
|----------|-------------|
| local rule metadata to planner | Rule code can return arbitrary metadata and capabilities; the planner must turn that into deterministic rows and controlled diagnostics. |
| internal plan to SDK view | The full internal plan must not cross into the supported public SDK surface. |
| rule panic/error containment | Rule metadata/capability calls may panic and must remain contained when invoked through runner integration. |
