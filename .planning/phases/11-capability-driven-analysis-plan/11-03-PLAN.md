<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parent CLI to child rule host | Parent delegates `explain plan` to Cargo-built local rule code. |
| child JSON to parent output | Parent parses child JSON and emits deterministic machine-readable output. |
| explain command to source tree | Explain must not parse or harvest source files by default. |
| untrusted rule capability request to diagnostics | Unsupported capability requests become structured diagnostics instead of silent empty facts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03-01 | Elevation of Privilege | `run_local_rule_host_explain_plan` | mitigate | Use `ProcessCommand` with explicit args; no shell strings; test delegation through temp local host. |
| T-11-03-02 | Tampering | `--format json` stdout | mitigate | Parse JSON in tests and compare raw stdout across three runs; human text must stay out of JSON output. |
| T-11-03-03 | Denial of Service | `polint explain plan` | mitigate | Tests prove invalid included source does not fail explain plan, because source parsing is not invoked. |
| T-11-03-04 | Repudiation | unsupported capability reporting | mitigate | Tests assert `polint/capability`, exact unsupported `cfg` message, and docs path in JSON diagnostics. |
| T-11-03-05 | Tampering | cache key behavior | mitigate | CLI test edits only a capability call and asserts new cache file names appear. |
</threat_model>
