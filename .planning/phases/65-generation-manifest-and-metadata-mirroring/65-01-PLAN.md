<threat_model>
## Security Baseline

OWASP ASVS Level 1 applies to this private local-cache boundary. Any unresolved
HIGH concern blocks R1 execution/closeout.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| existing SQLite file → migration/lifecycle code | Local cache state may be malformed, tampered with, foreign, or from a newer binary |
| pending candidate → active durable truth | Unvalidated or partially written state must never become readable |
| writer transaction → close/reopen reader | Rollback and committed selection must survive process/connection lifetime changes |
| private store subtree → kernel/public product | SQL, row IDs, table names, and rusqlite types must not become internal-crossing or public contracts |

## HIGH Blocking Threats

| Threat ID | ASVS area | Threat | Required mitigation and proof |
|-----------|-----------|--------|-------------------------------|
| T-65-01-01 | V5 validation | A claimed-current malformed database is accepted or silently repaired | Authenticate exact v2 shape, constraints, marker, contents, and foreign keys; return typed invalid-schema; malformed fixtures must pass without mutation. |
| T-65-01-02 | V1 architecture | Pending or merely newest state becomes active/readable | Complete-only relational foreign key plus explicit singleton read; no recency query; pending-selection negative test. |
| T-65-01-03 | V1 architecture / V5 validation | Partial publication destroys the prior active generation | One immediate transaction for transition+selection; deterministic failure at every mutation seam; close/reopen assertions authenticate old active and pending candidate. |
| T-65-01-04 | V1 architecture | SQL/row identity leaks beyond the private storage boundary | Opaque handle, crate-private facade, store-local raw handles/SQL, unchanged SDK/CLI/output, visibility/lint review. |

## Additional Threats

| Threat ID | Category | Threat | Mitigation |
|-----------|----------|--------|------------|
| T-65-01-05 | Denial of service | Lock contention blocks normal analysis indefinitely | Reuse the 250 ms busy timeout and typed `BusySkipped` mapping; do not introduce unbounded retries. |
| T-65-01-06 | Tampering | Older binary mutates a future schema | Preserve preflight future-version refusal and sentinel-state fixture. |
| T-65-01-07 | Repudiation | Shallow tests pass while relationships are wrong | Typed lifecycle snapshots, relational assertions, exact v1→v2 fixture, and reopen proof. |
| T-65-01-08 | Scope/contract exposure | R1 accidentally creates identities or public behavior later slices must support | Enforce the six-file/one-family/zero-provider boundary and stop-and-split rule. |
</threat_model>
