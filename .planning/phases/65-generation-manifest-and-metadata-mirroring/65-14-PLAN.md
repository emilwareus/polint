## Trust Boundaries

| Boundary | Description | Data Crossing |
|---|---|---|
| Snapshot/provider inputs to QueryKey | Query producers declare a subset of available analysis inputs | Capability/settings/model/extension digests |
| Pre-query dependency wire to final-query temporary wire | A serde-visible QueryKey change crosses layer-cache and invalidation schema guards | Schema labels, QueryKey rows, QueryDependencyInputs |
| Finalized kernel run to store handoff | Semantic rows and telemetry coexist before projection | Providers, layers, queries, facts, events, cache counters |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-65-14-01 | Tampering | Query dependency declaration | mitigate | Mandatory typed sorted inputs and referenced/unreferenced mutation tests. |
| T-65-14-02 | Denial of Service | Query invalidation | mitigate | Exact declarations prevent whole-snapshot over-invalidation. |
| T-65-14-03 | Spoofing | ValidatedRunMetadata completeness | mitigate | Integrity validator checks every family/reference/event before store access. |
| T-65-14-04 | Information Disclosure | Run handoff | mitigate | Retain payload_digest only and exact-test forbidden body/blob/source/path fields. |
| T-65-14-05 | Repudiation | Semantic/telemetry split | mitigate | Status/counter/duration/timestamp mutation tests preserve all identities. |
| T-65-14-06 | Spoofing | Dependency-index wire label | mitigate | Rotate to a unique temporary label before serialization and fail closed for v1 and the superseded temporary shape. |
