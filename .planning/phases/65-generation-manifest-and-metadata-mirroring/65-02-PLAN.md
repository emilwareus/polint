<threat_model>
## Trust Boundaries

| Boundary | Description | Data Crossing |
|---|---|---|
| Provider execution to semantic metadata | Runtime counters accompany provider identity | Output digests, validation, hit/miss/write counters |
| Demand engine to debug/store projections | Query results carry both identity and execution telemetry | QueryKey, cache status, duration, result digest |

## Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-65-02-01 | Tampering | Semantic digest projection | mitigate | Field-whitelisted projections and counter/status/duration mutation tests exclude telemetry. |
| T-65-02-02 | Spoofing | Provider/query statuses | mitigate | Closed enums and typed parsers reject unknown labels. |
| T-65-02-03 | Repudiation | Eval/debug compatibility | mitigate | Explicit legacy renderers and byte-compatible fixtures preserve observable telemetry. |
| T-65-02-04 | Denial of Service | Cache statistics aggregation | mitigate | Borrowed projections avoid cloning bodies and retain bounded counter aggregation. |
</threat_model>
