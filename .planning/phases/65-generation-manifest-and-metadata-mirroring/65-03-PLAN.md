<threat_model>
## Trust Boundaries

| Boundary | Description | Data Crossing |
|---|---|---|
| Loaded configuration to cache identity | One config contains both rule presentation and provider analysis settings | Rule options, language settings, solver/reachability settings |
| Analysis plan to capability identity | Rule metadata is projected into shared analysis requirements | Capability names, support/setup state, rule IDs/options |

## Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-65-03-01 | Tampering | Provider cache identity | mitigate | Closed provider scopes and paired relevant/unrelated mutation tests prevent full-config contamination. |
| T-65-03-02 | Denial of Service | Cache reuse | mitigate | Rule-only severity/files/max/options mutations are excluded from analysis keys to prevent avoidable recomputation. |
| T-65-03-03 | Spoofing | Capability analysis projection | mitigate | Typed capability/language/status rows and exact canonical sorting replace opaque plan digests. |
| T-65-03-04 | Information Disclosure | Configuration projection | mitigate | Persist only normalized digests/details; never store environment values or absolute paths. |
</threat_model>
