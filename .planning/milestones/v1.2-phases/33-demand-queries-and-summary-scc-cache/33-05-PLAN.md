<objective>
Implement the extension-aware cache quarantine mechanism per D-08, D-09, D-10.

Purpose: When an extension's code or manifest digest changes, cache entries that include that extension's digest are quarantined (not served as hits, not deleted). If the extension reverts, quarantined entries are reinstated. Native facts are never quarantined per D-09. This is infrastructure for Phase 34 (extension/provider sink). Per D-10, the mechanism is exercised through synthetic extension digests following the Phase 22 pattern.

Output: New quarantine.rs module with QuarantineStore. Existing invalidation.rs quarantine action integrated with the store. Synthetic extension tests prove the mechanism.
</objective>

  <action>
    Create quarantine.rs as a new crate-private module under analysis_kernel/incremental/.

    Define QuarantineEntry (Clone, Debug, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize) with fields: node (CacheNode), reason (QuarantineReason), extension_digest_at_quarantine (Digest — the extension digest that triggered quarantine), and quarantined_at_run (u64 — run ID for age tracking).

    Define QuarantinePolicy (Clone, Debug, Default) with fields: max_quarantine_age_runs (u64, default 10 — entries older than this are evicted on next cleanup).

    Define QuarantineStore (Clone, Debug, Default, Serialize, Deserialize) with fields: entries (BTreeMap of CacheNode to QuarantineEntry) and policy (QuarantinePolicy). Implement methods:
    - quarantine(&mut self, node: CacheNode, reason: QuarantineReason, extension_digest: Digest, run_id: u64) — adds or updates quarantine entry. Rejects nodes that are native-only (Layer nodes with empty extension_digests, determined by checking if the node is a CacheNode::Layer whose extension_digests are all absent sentinels per D-09).
    - is_quarantined(&self, node: &CacheNode) -> bool — checks if node is quarantined.
    - reinstate(&mut self, extension_digest: &Digest) -> Vec<CacheNode> — removes all quarantine entries whose extension_digest_at_quarantine matches the given digest (extension reverted to known-good state per D-08). Returns the reinstated nodes.
    - cleanup(&mut self, current_run_id: u64) — evicts entries older than max_quarantine_age_runs.
    - quarantine_count(&self) -> usize
    - quarantined_nodes(&self) -> Vec<&CacheNode>

    Add a helper function is_native_only_node(node: &CacheNode) -> bool that returns true for CacheNode::Layer nodes with extension_digests all being absent sentinels (contain "absent" in display), CacheNode::Input, and CacheNode::ToolInvocation. Returns false for CacheNode::Extension, CacheNode::Query, CacheNode::Summary, and CacheNode::Diagnostic (those can be extension-influenced). Per D-09, native facts are never quarantined.

    In mod.rs, add pub(crate) mod quarantine; and re-export QuarantineStore, QuarantineEntry, QuarantinePolicy.

    Add unit tests:
    (a) Quarantine a Summary node with extension digest "ext-v1", verify is_quarantined returns true.
    (b) Reinstate with digest "ext-v1", verify the node is no longer quarantined and is returned in the reinstated list.
    (c) Attempt to quarantine a native-only Layer node (extension_digests all absent), verify it is rejected and not quarantined.
    (d) Quarantine two nodes with different extension digests, reinstate only one digest, verify the other remains quarantined.
    (e) Cleanup evicts entries older than max_quarantine_age_runs.
  </action>
