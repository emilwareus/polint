<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Test fixture cache -> real providers | Eval fixtures mutate and reuse cache data across cold/warm/stale runs using real provider execution. |
| Malicious cache files -> filesystem | Path traversal, symlink escape, corrupt JSON, malformed payloads, and unsupported schemas must fail closed. |
| Internal observability -> public output | Eval/run-report cache stats must not leak into stable public JSON, CLI help, SDK, runner, crate-root exports, or docs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-05-01 | Tampering | native layer-cache fixture | mitigate | Fixture uses real Go/TS/module/symbol/metrics providers and asserts import edits invalidate dependent layers. |
| T-24-05-02 | Tampering | corrupt layer payloads | mitigate | Stale-entry tests cover corrupt JSON, wrong shape, mismatched digests, and unsupported schemas as invalid reads/misses. |
| T-24-05-03 | Elevation of Privilege | path traversal/symlink escape | mitigate | LayerCacheStore rejects `../`, absolute paths, symlinks, and any manifest-supplied path outside managed cache root. |
| T-24-05-04 | Information Disclosure | public JSON/cache manifests | mitigate | Public no-leak test rejects cache-internal markers; manifest tests reject raw source, absolute paths, temp roots, timestamps as identity, and run IDs. |
| T-24-05-05 | Repudiation | hit/miss stats | mitigate | Eval asserts deterministic per-layer and aggregate hit/miss/recompute/write/disabled-bypass/invalid/verified-reuse counters. |
| T-24-05-06 | Denial of Service | stale/corrupt cache | mitigate | Normal analysis recomputes on invalid reads instead of crashing. |
| T-24-05-07 | Spoofing | public API leakage | mitigate | Source-surface tests assert `LayerCacheManifest`, `DependencyIndex`, `InvalidationPlan`, and stats markers are absent from public exports. |
| T-24-05-08 | Tampering | stale module/symbol reuse | mitigate | Eval import/config/lifecycle scenario proves dependent module/symbol layers miss/recompute while unrelated syntax stays reusable. |
</threat_model>
