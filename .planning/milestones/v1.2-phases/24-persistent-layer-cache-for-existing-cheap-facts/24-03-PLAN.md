<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cached module graph -> `AnalysisDb` | Resolved imports and graph facts are restored from disk only after key/dependency/output validation. |
| Source/lifecycle/config changes -> module reuse | Conservative invalidation must block stale module topology when imports, Go/TS lifecycle, config, provider/schema, source/package inputs, or upstream syntax output changes. |
| Internal module stats -> public output | Module layer cache stats stay inside run reports/eval/test helpers and do not alter public `polint check` JSON. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-03-01 | Tampering | module graph cache payload | mitigate | Validate manifest key, dependency-layer digests, payload digest, schema, and cached output-digest metadata before merging graph facts; propagate the hit outcome's `output_digest` to provider metadata. |
| T-24-03-02 | Spoofing | import/lifecycle identity | mitigate | Include import-shape, source/package, config, lifecycle, provider/schema, toolchain digest slots, and upstream syntax digests in key/dependency edges. |
| T-24-03-03 | Information Disclosure | module graph manifest | mitigate | Persist normalized relative fact identities only; no absolute paths, raw source text, temp roots, timestamps as identity, or run IDs. |
| T-24-03-04 | Denial of Service | corrupt module graph cache | mitigate | Corrupt or deserialization-failing entries are invalid reads followed by recompute. |
| T-24-03-05 | Elevation of Privilege | public API leakage | mitigate | Keep all cache helpers crate-private and verify public output remains unchanged in later proof plan. |
| T-24-03-06 | Tampering | stale module graph reuse | mitigate | Unknown shape classification or missing dependency index rows force recompute rather than reuse. |
| T-24-03-07 | Repudiation | disabled module cache | mitigate | Disabled mode records `bypasses_disabled` for `polint.module_graph` and performs normal derivation without cache file reads or writes. |
</threat_model>
