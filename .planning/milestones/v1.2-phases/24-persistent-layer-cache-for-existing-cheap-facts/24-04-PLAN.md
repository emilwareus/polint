<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cached symbol/metrics payloads -> SDK-visible facts | Restored facts become visible to existing typed SDK views after validation. |
| Upstream layer digests -> derived reuse | Symbol and metrics reuse depends on syntax/module output digests and must not trust stale upstream outputs. |
| External rule behavior -> cache restore proof | Public rules must observe identical facts on cold and warm runs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-04-01 | Tampering | symbol graph cache payload | mitigate | Validate key, provider/schema, upstream module/syntax output digests, payload digest, and cached output-digest metadata before restoring symbols/references; propagate the hit outcome's `output_digest` to provider metadata. |
| T-24-04-02 | Tampering | metrics cache payload | mitigate | Validate key, source/function/syntax inputs, payload digest, and cached output-digest metadata before restoring metrics facts; propagate the hit outcome's `output_digest` to provider metadata. |
| T-24-04-03 | Spoofing | stale upstream dependency | mitigate | Include module graph and syntax provider output digests in derived layer keys and dependency edges. |
| T-24-04-04 | Information Disclosure | persisted derived facts | mitigate | Persist normalized relative identities only; no raw source, absolute paths, timestamps as identity, temp roots, or run-local IDs. |
| T-24-04-05 | Denial of Service | corrupt symbol/metrics cache | mitigate | Corrupt or deserialization-failing entries are invalid reads followed by recompute. |
| T-24-04-06 | Elevation of Privilege | public API leakage | mitigate | Do not export cache internals; reuse existing public SDK tests to prove behavior compatibility without new surface. |
| T-24-04-07 | Repudiation | hit/miss reporting | mitigate | Attach real per-provider stats to `KernelRunReport` for `polint.symbol_graph` and `polint.metrics`. |
| T-24-04-08 | Repudiation | disabled derived-layer caches | mitigate | Disabled mode records `bypasses_disabled` for symbol and metrics providers and performs normal derivation without cache file reads or writes. |
</threat_model>
