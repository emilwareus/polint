<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Disk syntax layer -> `AnalysisDb` | Cached Go/TS syntax facts become trusted parser facts only after manifest/key/payload/output validation. |
| Rule crate edits -> syntax cache identity | External user rule code changes must not spoof syntax invalidation inputs or stale syntax reuse. |
| Cache payload serialization -> source confidentiality | Syntax payloads must exclude raw source text and machine-local absolute paths. |
| Internal stats -> public JSON | Hit/miss/reuse counters must stay crate-private/test-facing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-02-01 | Tampering | Go/TS syntax layer reads | mitigate | Validate manifest key, schema, provider version, payload digest, deserialization, and cached output-digest metadata before merging facts into `AnalysisDb`; use the hit outcome's `output_digest` rather than requiring it before the read. |
| T-24-02-02 | Repudiation | syntax cache stats | mitigate | Record deterministic `hits`, `misses`, `recomputes`, `writes`, `bypasses_disabled`, `invalid_evicted_reads`, and `verified_reuse` counters in `CacheStats`. |
| T-24-02-03 | Information Disclosure | syntax payloads | mitigate | Store normalized facts/diagnostics only; tests grep cache payloads for absent source bodies and absolute temp roots. |
| T-24-02-04 | Denial of Service | corrupt syntax cache | mitigate | Corrupt manifests/payloads are invalid reads followed by recompute, not process crashes. |
| T-24-02-05 | Elevation of Privilege | public API leakage | mitigate | No SDK/runner/CLI exports; integration test asserts public JSON and source surfaces exclude layer-cache/internal stat markers. |
| T-24-02-06 | Spoofing | unrelated rule edit invalidation | mitigate | Syntax `LayerKey` excludes rule code/options digests unless future parser params genuinely consume them; regression locks this behavior. |
</threat_model>
