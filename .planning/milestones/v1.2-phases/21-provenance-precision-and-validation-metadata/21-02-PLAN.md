<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Derived providers -> AnalysisDb | Module, symbol, and metrics providers replace derived fact vectors and attach metadata. |
| Family-specific truth -> shared metadata | Resolution and symbol precision/status fields are summarized into shared metadata without deleting the original fields. |
| Test-only coverage report -> crate internals | Missing-metadata reports support tests and must not become public contracts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-02-01 | Spoofing | derived provider metadata | mitigate | Hard-code producer ids to `polint.module_graph`, `polint.symbol_graph`, and `polint.metrics`; tests grep and assert values. |
| T-21-02-02 | Tampering | symbol/reference stable keys | mitigate | Reuse existing `stable_key` fields exactly for symbol, definition, and reference metadata so metadata identity cannot drift from established symbol graph identity. |
| T-21-02-03 | Repudiation | missing metadata gaps | mitigate | Add deterministic `MissingFactMeta` rows sorted by family/run id so coverage failures identify the missing family precisely. |
| T-21-02-04 | Information Disclosure | missing metadata report | mitigate | Keep report APIs crate-private and test-facing; no SDK, runner, crate-root public, or CLI export. |
</threat_model>
