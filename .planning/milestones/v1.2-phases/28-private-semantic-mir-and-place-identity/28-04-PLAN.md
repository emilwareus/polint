<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Oxc AST -> MIR rows | Oxc AST nodes, spans, and lifetimes are implementation details that must not escape. |
| TS/JS dynamic constructs -> downstream analyses | Dynamic semantics must be represented as unsupported/unknown rows with conservative actions. |
| call-shaped MIR -> direct-call phases | Calls are shape evidence only, not target resolution or public call graph behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-04-01 | I | TS/JS lowering output | mitigate | Contract grep checks ensure emitted MIR/place row structs do not contain Oxc AST/span/lifetime types. |
| T-28-04-02 | T | Dynamic properties and destructuring | mitigate | Emit unknown projections and structured unsupported rows instead of silently treating dynamic access as exact. |
| T-28-04-03 | R | Async/callback/dynamic JS behavior | mitigate | Emit unsupported rows for await/yield, async rejection gaps, JSX callback scheduling, proxies, getters/setters, and eval/with. |
| T-28-04-04 | E | Direct-call overreach | mitigate | Keep call rows as `MirOperationKind::Call`; no direct target facts, call indexes, or public graph views are added. |
</threat_model>
