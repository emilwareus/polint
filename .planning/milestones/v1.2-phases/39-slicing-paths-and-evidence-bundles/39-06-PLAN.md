<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| extension facts -> evidence graph | Extension data is less trusted than native analysis and must be validated before merge. |
| extension precision -> diagnostics | Optional extension precision must not let diagnostics overclaim certainty. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T39-12 | Tampering | evidence merge | Mitigated | Reject invalid endpoints and keep native may-edges even when extension evidence proposes a narrower result. |
| T39-13 | Spoofing | precision status | Mitigated | Downgrade extension exactness unless validation proves native anchors and replay keys. |
| T39-14 | Information Disclosure | extension debug rows | Mitigated | Render relative paths/reason codes only; test that raw source and absolute roots are absent. |
</threat_model>
