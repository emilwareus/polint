<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internal facts -> evidence graph | Evidence rows must reference existing stable facts rather than forging analysis truth. |
| evidence graph -> public reports | Structured internals must not leak as public SDK or unsupported report schema. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T39-01 | Tampering | evidence stable keys | Mitigated | Derive stable keys from source fact stable keys and query parameters, never dense ids. |
| T39-02 | Information Disclosure | evidence labels | Mitigated | Store compact labels and relative paths only; reject raw source and absolute paths in debug/eval tests. |
| T39-03 | Repudiation | replay keys | Mitigated | Include graph version, query mode, budgets, ranking, and upstream digests in replay keys. |
</threat_model>
