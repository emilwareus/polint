<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internal evaluation model -> serialized JSON | Crate-private data becomes machine-readable output for tests and future adapters. |
| Local filesystem -> report/hash | Paths from fixtures or temp repos must not leak machine-local absolute roots into deterministic output. |
| Internal module -> public API | The eval model must not become an SDK, runner, crate-root public module, or public CLI contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-01-01 | Information Disclosure | `eval::report` | mitigate | Hash and JSON helpers exclude timestamps, absolute roots, temp roots, process ids, pointer-like formatting, and raw elapsed durations; tests grep for these fields. |
| T-22-01-02 | Tampering | report ordering | mitigate | Normalize and sort cases, expected items, observed items, matches, and metrics before serialization and hashing. |
| T-22-01-03 | Spoofing | public API boundary | mitigate | Register `eval` only as `pub(crate) mod eval;` and grep for absence of `pub mod eval` and bare public eval item declarations. |
| T-22-01-04 | Repudiation | deterministic hashes | mitigate | Unit tests prove semantically identical data hashes identically while stable keys/fingerprints/endpoints/path nodes/invariant values alter the hash. |
</threat_model>
