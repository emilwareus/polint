<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| summaries -> data-flow | Missing or unknown summaries must not be interpreted as no-flow. |
| refined calls -> data-flow | Refined call facts are upstream inputs; data flow must not create a provider cycle. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T38-G04 | Tampering | summary projection | Mitigated | Require summary stable key and status evidence on every summary-projected row. |
| T38-G05 | Information Disclosure | summary payloads | Mitigated | Use compact payload digests and labels, not raw callee bodies or source. |
| T38-G06 | Denial of Service | interprocedural expansion | Mitigated | Project compact summary edges; defer full path expansion to query/evidence phases. |
</threat_model>
