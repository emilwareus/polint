<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MIR facts -> data-flow facts | Unsupported or unknown MIR semantics must not become exact flow claims. |
| query budgets -> results | Bounded search must not report clean no-flow when traversal was truncated. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T38-G01 | Tampering | local flow stable keys | Mitigated | Build edge identity from source/target place stable keys, operation stable key, edge kind, and assignment mode evidence. |
| T38-G02 | Information Disclosure | uncertainty evidence | Mitigated | Store compact evidence labels and stable keys only; never raw source bodies or parser object ids. |
| T38-G03 | Denial of Service | path search | Mitigated | Persist explicit budget rows and bounded path status instead of unbounded traversal. |
</threat_model>
