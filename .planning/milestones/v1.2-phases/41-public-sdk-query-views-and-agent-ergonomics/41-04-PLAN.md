<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public inspection commands -> internal debug output | Public commands must not reuse unstable debug schemas as public JSON. |
| sampling -> source privacy | Samples must not dump raw source bodies or machine-local paths. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T41-07 | Information Disclosure | facts/unknowns sample output | Mitigated | Limit fields to public facts, relative paths, stable IDs, and bounded counts. |
| T41-08 | Denial of Service | expensive fact/path queries | Mitigated | Require explicit limits and support only existing stable capability families. |
</threat_model>
