<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Parent CLI -> child rule host | Parent executes user-owned `.polint/rules` Cargo packages to retrieve manifests. |
| Child manifest JSON -> parent merge | Child JSON is parsed and merged into parent public output. |
| Rule manifest -> public JSON | Internal manifest data becomes a supported public CLI contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-02-01 | Spoofing | child inspect delegation | mitigate | Run only manifests discovered from configured `[rules].paths`; parse child JSON into the expected report shape before merging. |
| T-25-02-02 | Tampering | merged report ordering | mitigate | Sort merged manifests by host path and rule id; test byte-identical repeated output. |
| T-25-02-03 | Information Disclosure | inspect JSON | mitigate | Wire model excludes internal kernel/cache/provider/source/temp fields and tests reject internal markers. |
| T-25-02-04 | Denial of Service | source analysis during inspect | mitigate | Inspect path must not call `AnalysisKernel::run`, source discovery, ignore processing, or rule execution. |
| T-25-02-05 | Repudiation | missing rule selectors | mitigate | Missing selectors return deterministic nonzero errors rather than silent empty success. |
</threat_model>
