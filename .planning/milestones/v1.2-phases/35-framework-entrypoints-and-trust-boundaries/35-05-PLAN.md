<objective>
Wire Go and TS/JS recognizers into the provider, derive trust boundary facts from recognized entrypoints, derive dispatch edge facts, and merge unresolved framework facts. This completes the provider's data pipeline.

Purpose: Per D-19, D-20, D-21 trust boundaries are per-entrypoint per-source-kind facts. Per D-04 dispatch edges are synthetic call edges. Per D-05 and D-10 unresolved facts are honest uncertainty. This plan connects all data sources through the provider so the kernel produces populated output.
Output: Provider produces populated EntrypointOutput with all four fact families from real recognizer data.
</objective>

    Create analysis/entrypoints/extract.rs:
    pub(crate) fn extract_entrypoints(db: &AnalysisDb) -> EntrypointOutput.
    1. Call recognize_go_entrypoints(db) and recognize_ts_entrypoints(db).
    2. Merge entrypoint vecs into one combined list.
    3. Call derive_trust_boundaries(db, &entrypoints) to produce trust boundary facts.
    4. Call derive_dispatch_edges(db, &entrypoints) to produce dispatch edge facts.
    5. Call merge_unresolved(go_unresolved, ts_unresolved) to combine unresolved facts.
    6. Return EntrypointOutput { entrypoints, trust_boundaries, dispatch_edges, unresolved }.

    Create analysis/entrypoints/trust_boundaries.rs (per D-03, D-19, D-20, D-21, D-22):
    pub(crate) fn derive_trust_boundaries(db: &AnalysisDb, entrypoints: &[EntrypointFact]) -> Vec of TrustBoundaryFact.

    For each entrypoint, derive source-kind-specific trust boundary facts based on the entrypoint kind:

    HttpRoute entrypoints:
    - Emit TrustBoundaryFact with source_kind PathParam (if trigger_metadata.path contains parameter placeholders like /:id or {id}).
    - Emit TrustBoundaryFact with source_kind QueryString (HTTP routes always accept query strings).
    - Emit TrustBoundaryFact with source_kind RequestBody (for POST, PUT, PATCH, DELETE methods).
    - Emit TrustBoundaryFact with source_kind RequestHeader (all HTTP routes receive headers).

    HttpMiddleware entrypoints:
    - Emit TrustBoundaryFact with source_kind RequestBody, RequestHeader, QueryString.

    McpTool entrypoints:
    - Emit TrustBoundaryFact with source_kind McpArguments.

    McpResource entrypoints:
    - Emit TrustBoundaryFact with source_kind McpResourceUri.

    McpPrompt entrypoints:
    - Emit TrustBoundaryFact with source_kind McpArguments.

    CliCommand entrypoints:
    - Emit TrustBoundaryFact with source_kind CliArgs and CliFlags.

    Test entrypoints:
    - No trust boundary facts (tests are not external-facing).

    Job/QueueConsumer entrypoints:
    - Emit TrustBoundaryFact with source_kind QueuePayload.

    For all others (ServerlessHandler, LifecycleCallback, EventListener, GeneratedDispatch):
    - Emit TrustBoundaryFact with source_kind Unknown (per D-20, mandatory for entrypoints where source kind cannot be determined).

    Trust boundary precision follows entrypoint precision (per D-21). Use the entrypoint's provider_id. Generate stable keys using semantic_stable_key(FactFamily::TrustBoundary, &[("entrypoint_key", ...), ("source_kind", ...), ("language", ...)]).

    Create analysis/entrypoints/dispatch.rs (per D-04):
    pub(crate) fn derive_dispatch_edges(db: &AnalysisDb, entrypoints: &[EntrypointFact]) -> Vec of FrameworkDispatchEdgeFact.

    For each entrypoint with a resolved target_function, emit a FrameworkDispatchEdgeFact:
    - from_source: a synthetic framework dispatch root key built from framework_id + kind
    - to_target: the entrypoint's target_function
    - to_symbol: the entrypoint's target_symbol
    - edge_kind: map EntrypointKind -> DispatchEdgeKind (HttpRoute/HttpMiddleware -> RouteDispatch/MiddlewareChain, McpTool/McpResource/McpPrompt -> McpDispatch, Test -> TestRunner, CliCommand -> RouteDispatch, Job/QueueConsumer -> JobScheduler, LifecycleCallback -> LifecycleHook, EventListener -> EventDispatch, GeneratedDispatch -> RouteDispatch)
    - precision: match entrypoint precision.

    Generate stable keys using semantic_stable_key(FactFamily::DispatchEdge, &[("from", ...), ("to_function_key", ...), ("edge_kind", ...), ("language", ...)]).

    Create analysis/entrypoints/unresolved.rs:
    pub(crate) fn merge_unresolved(go: Vec of UnresolvedFrameworkFact, ts: Vec of UnresolvedFrameworkFact) -> Vec of UnresolvedFrameworkFact.
    Combine the two vecs, dedup by stable_key (keep first occurrence), sort by stable key.

    Update analysis/entrypoints/mod.rs to declare pub(crate) mod extract, trust_boundaries, dispatch, unresolved.

    Add #[cfg(test)] modules for trust boundary derivation (HTTP entrypoint produces PathParam, QueryString, RequestBody, RequestHeader boundaries; MCP entrypoint produces McpArguments boundary; CLI produces CliArgs and CliFlags; Test produces no boundaries) and dispatch edge derivation.
