    pub(crate) fn validate_summaries(db: &AnalysisDb, diagnostics: &mut Vec of Diagnostic):
    1. Collect valid function ID set from db (FunctionId set from source/syntax functions).
    2. Check duplicate stable keys via check_duplicate_stable_keys helper for each summary fact family (SummaryControl, SummaryCall, SummaryMemory, SummaryTito).
    3. For each summary fact row:
       a. Validate function reference exists in the function ID set. If dangling, push diagnostic with push_summary_diagnostic helper.
       b. Validate callable_stable_key is non-empty.
       c. Validate domain field matches expected fact family (ControlEffects facts should have SummaryControl family metadata).
       d. Validate payload_digest is non-empty.
    4. Check metadata precision ceilings: for each summary-related FactFamily, iterate fact_meta rows and reject FactPrecision::Exact (summary provider ceiling is SetupAware per manifest). Push diagnostic if ceiling violated.
    5. For each summary event fact: validate callable_stable_key non-empty, function exists, event_kind and reason are non-empty.

    push_summary_diagnostic helper: same pattern as push_domain_diagnostic, using tracing::debug and Diagnostic::error with "polint/internal" rule.

    Add pub(crate) mod validate to summaries/mod.rs.

    Wire into analysis_kernel/validation.rs: add use crate::analysis::summaries::validate::validate_summaries and call validate_summaries(db, &mut diagnostics) after validate_abstract_domains.

    Add tests:
    - rejects_dangling_function_reference
    - rejects_duplicate_stable_keys
    - rejects_exact_precision_on_summary_metadata
    - accepts_valid_summary_facts
