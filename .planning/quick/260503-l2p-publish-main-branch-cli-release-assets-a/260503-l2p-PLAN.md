# Quick Task 260503-l2p: Publish main-branch CLI release assets and install script

**Date:** 2026-05-03
**Status:** Complete

## Goal

Make `polint` installable from a private GitHub repository with a one-liner.
Build signed-by-checksum release assets through GitHub Actions only from `main`,
then provide an install script that downloads the correct asset through the
authenticated GitHub CLI.

## Tasks

1. Add a `main`-only GitHub Actions workflow that builds Linux and macOS release
   archives for the `polint` binary and uploads them to a stable `polint-main`
   GitHub release.
2. Add `scripts/install.sh` that detects the local OS/architecture, downloads
   the matching private release asset with `gh release download`, verifies the
   SHA-256 checksum, and installs `polint` into a user-writable global bin dir.
3. Update the README installation section with the private-repo one-liner and
   release channel behavior.
4. Run shell syntax checks plus normal Rust checks affected by the workflow/docs
   changes.
