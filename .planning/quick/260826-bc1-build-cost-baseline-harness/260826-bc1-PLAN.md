# Plan

Add a repeatable build-cost measurement harness for the current Cargo rule-host
path, so the code-preserving rule-build work has measured numbers instead of the
three unverified figures carried in
`research/code-preserving-rule-build/IMPLEMENTATION-PLAN.md` §0 (223 compiled
units, 185.4 s cold build, 537 MB retention).

Scope is the plan's first implementation slice (§14.2, Phase A tasks A1–A4).
No product behaviour changes; nothing under `crates/polint/src` is touched.

## Tasks

1. `polint-bench build-cost`: scenario runner that drives the real `polint`
   CLI against a scratch copy of a target repo and records, per run:
   Cargo invocations, rustc invocations / compiled units, wall-clock,
   rule-host wall-clock and peak RSS, and bytes written / retained in the
   rule-host `CARGO_TARGET_DIR` and the polint cache, plus the
   `CARGO_HOME/registry` byte delta.
2. Cargo/rustc shim: `POLINT_CARGO` points at the bench binary, which records
   each Cargo invocation and installs itself as `RUSTC_WRAPPER` so compiled
   units are counted from real rustc invocations rather than estimated.
3. Scenario matrix: `cold`, `warm-noop`, `warm-rule-edit`, `warm-source-edit`,
   `test-suite`, over one or more example repos.
4. `make build-cost` (diff against the committed baseline) and
   `make build-cost-baseline` (rewrite it).
5. Committed measured baseline at
   `research/evaluation-harness/baselines/build-cost.json`
   (`schema_version = polint-build-cost-1`), with metric definitions and the
   exact environmental limits documented in
   `research/evaluation-harness/README.md`.

## Constraints

- Rules stay real, typed, expressive Rust. No DSL, no rule-source changes.
- No files under `crates/polint/src` change; peak RSS is obtained by reusing
  the existing `POLINT_GOLDEN_COST_PATH` sidecar (`golden_cost.rs` ->
  `measure::TimedRun`), not by adding new instrumentation to the engine.
- No fabricated numbers. Metrics the harness cannot measure are `null` with a
  recorded reason; unavailable reference machines are documented, not invented.
- Committed artifacts carry no machine-local absolute paths
  (`research/evaluation-harness/baselines/README.md`).
- Scratch state lives under `target/`, which is gitignored.

## Verification

- `cargo fmt --all -- --check`
- `cargo clippy -p polint-bench --all-targets --all-features --locked -- -D warnings`
- `cargo test -p polint-bench --locked`
- A real end-to-end run of the harness, with its output recorded.
