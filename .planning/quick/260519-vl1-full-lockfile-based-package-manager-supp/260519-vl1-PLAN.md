# Quick Task 260519-vl1: Full lockfile-based package manager support

**Date:** 2026-05-19
**Status:** Complete

## Goal

Support real lockfile-based package manager detection for TS/JS topology while keeping Go on the existing `go.mod` / `go.sum` model.

## Tasks

1. Add crate-private lockfile parser support for npm, pnpm, Yarn, and Bun.
   - Parse `package-lock.json`, `npm-shrinkwrap.json`, `pnpm-lock.yaml`, Yarn v1/v2+ `yarn.lock`, and text `bun.lock`.
   - Keep unsupported and malformed lockfiles as controlled topology uncertainty, not panics.

2. Replace npm-only TS topology lockfile emission with package-manager selection.
   - Prefer `packageJson#packageManager` when valid.
   - Infer from one supported lockfile when no manager is declared.
   - Report ambiguity or missing selected lockfiles without guessing.
   - Ignore legacy `bun.lockb`.

3. Update topology cache inputs and regression coverage.
   - Add `npm-shrinkwrap.json` to topology/lifecycle digests.
   - Remove `bun.lockb` from supported lockfile inputs.
   - Test positive, conflict, missing, ambiguous, malformed, and cache invalidation scenarios.
