# W4.5 LAND — constant and nilness IDE domains

## Result

- `IdeDomainSolver` is the sole production solver for the existing abstract
  domains. It runs the unchanged constant, nilness, truthiness, string,
  initializedness, and reachability lattices over W4.2's matched ICFG.
- Resolved calls project caller arguments into callee parameters. Matched
  returns project callee return values into the caller result place while
  preserving caller-local and global state.
- Context-sensitive exploded points carry the active call-site stack.
  Unmatched returns are rejected, and context-specific states are joined only
  when materializing the existing domain observation schema.
- W4.3's taint sanitizer kills remain in the same IFDS module and are unchanged.

## Deleted path

- Deleted the per-function `LocalDomainSolver` production path and migrated the
  provider and evaluation harness directly to `IdeDomainSolver`.
- Resolved calls no longer use the intraprocedural unknown-return transfer.
  There is no fallback, feature flag, compatibility shim, or dual solver.

## Regression

- `ide_solver_maps_constant_and_nilness_through_matched_call_and_return` proves
  that an existing constant and its derived nilness cross a real resolved call
  and return through parameter/result projection.
- Existing domain tests continue to cover deterministic joins, widening,
  budgets, branch refinement, and materialization.
- Existing IFDS tests continue to cover matched returns and W4.3 sanitizer
  kills.
