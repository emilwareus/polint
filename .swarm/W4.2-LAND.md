# W4.2 LAND — matched IFDS paths over the ICFG

## Result

- `analysis/ifds::Icfg::from_facts` constructs the ICFG from stored CFG
  functions, nodes, and edges plus resolved refined-call targets. It emits
  intraprocedural, call, call-to-return, and matched return edges without
  reparsing source.
- `analysis/ifds::find_paths` is the production entrypoint used by
  `policy_queries::forbidden_data_flows`. Its exploded state carries the
  reachable fact and call stack, and its deterministic worklist rejects
  returns that do not match the active call site.
- Go and TypeScript/JavaScript data-flow paths use the same matched engine.
  Empty matched results remain honest `NotFound`, `Unknown`, or
  `BudgetExceeded` results.

## Deleted path

- Deleted `analysis/data_flow/query.rs::find_paths`, the unmatched per-path BFS
  used by production policy flow queries.
- Deleted the old data-flow query module; there is no fallback, feature flag,
  or dual path finder.

## Regression

- `analysis::ifds::tests::solver_rejects_unrealizable_path_with_mismatched_return_site`
  proves that a path entering one call site cannot return through another.
- `analysis::ifds::tests::icfg_builds_call_to_return_and_matched_return_edges`
  verifies ICFG construction from existing facts.
